# 公平线索与诡计工艺（推理 / 悬疑 · 可选工具箱）

> **定位**：类型向技法参考，**非** always 强制全文套用。强制底线在 `rules/02-novel-plot-design.mdc` 与 `00-novel-values.mdc`。  
> **用这个**：作品含解谜内核（谁做的 / 怎么做到的 / 为何如此），且承诺读者可以自己推。  
> **不是那个**：悬念惊悚的「不给答案也行」、犯罪过程的沉浸式跟拍、靠隐瞒真值硬拗的反转。

## 1. 公平性原则（读者可解性）

三条底线，缺一即失约：

1. **侦探不得使用未向读者展示的信息**——解谜者可以更聪明，不可以更有权限。  
2. **线索必须在揭晓前出现**——读者与解谜者面对同一份材料，只是读法不同。  
3. **可解但不必猜中**——目标是揭晓后读者能回溯复核并服气，不是让读者抢先报答案。

| 项 | ❌ | ✅ |
|---|---|---|
| 关键证据 | 揭晓段首次登场 | 早已露面，只是当时不起眼 |
| 解谜依据 | 「我早查出某件事」 | 读者读过同一句话 |
| 意外感来源 | 信息空白 | 读者看过却没读懂 |

## 2. 线索分级与配比

| 级别 | 功能 | 数量配比 | 放置位置 |
|------|------|----------|----------|
| **核心线索** | 唯一解的必要件，缺一不可解 | 每案 3–5 条，占线索总量约两成 | **开篇窗内至少 1 条**；其余散布于调查段 |
| **辅助线索** | 收窄范围、确认方向 | 约为核心的 2–3 倍 | 与对应核心线索邻位出现，作二次加固 |
| **红鲱鱼（误导）** | 支撑错误假设 | 每案 1–2 条，**宜少** | 中段，且须与某条核心线索同场登场 |
| **氛围干扰** | 质感与噪音，不承载推理 | 不限 | 任意；**不得占用线索位** |

- 核心线索一条只服务一个推论；一条线索撑起半个真相 → 拆。  
- 开篇窗内的核心线索宜走「不起眼」路线：在场、被提过、未被议论。  
- 数量配比写进 `主题/通用约束.md`，不写进母版死值。

## 3. 诡计类型表

| 诡计 | 作者要管的变量 | 最容易破功的点 |
|------|----------------|----------------|
| **密室** | 出入口的物理条件、时间窗、在场者证词、凶器去向 | 解法依赖未交代的构造或机关；读者无法自行排除 |
| **不在场证明** | 计时口径、代行者、目击者认定的依据 | 时间口径前后不一（并入量纲检查）；证明被推翻却无痕 |
| **身份错位** | 谁被认成谁、认错的凭据、调换发生的时机 | 靠读者「没看清」而非「看错」；凭据单薄 |
| **叙述性诡计** | 叙述者的信息边界、指代的可双解性 | 叙述者回避直答；用隐瞒替代歧义 |
| **时间线错位** | 讲述顺序与事件顺序的错位、锚点事件 | 读者无法回溯重排；错位只为制造晕眩 |
| **物证误读** | 谁在何条件下观察到它、为何误读 | 关键物证揭晓才首次出现；误读无合理成因 |

选诡计先问：**读者读完能不能自己重排一遍**。不能，则不是本格，是悬念。

## 4. 误导的正确用法

- **红鲱鱼要能自圆其说**：被怀疑者须有独立动机与独立行为，退场时给出交代，不得凭空消失。  
- ❌ 靠隐瞒制造惊讶：叙述者明知真值却陈述相反。  
- ✅ 靠误导制造「我早该看出」：材料齐全，读法被引偏。  
- **惊讶 ≠ 意外**：惊讶有伏笔，意外只有空白。反向惊喜的力量来自读者复盘时的自省。  
- 误导只能由**角色**主动施加（撒谎、栽赃、误判）；作者不得替角色撒谎。  
- 一条红鲱鱼若始终无人解释，读者会把整章当漏洞，而不是当误导。

## 5. 真相揭晓节奏

| 阶段 | 要做的事 |
|------|----------|
| **揭晓前** | 放「最后一次公平提示」：在揭晓段之前约 5–10% 篇幅内，用一条已出现过的物件或话语完成提示 |
| **揭晓时·先回收** | 按登场顺序回收读者记得的核心线索，一条一句，让人不断点头 |
| **揭晓时·后补盲区** | 再补读者未见的部分；补充信息量不超过解密所需总量的约两成 |
| **揭晓后** | 动机与代价落地；给被误指者一个交代 |

- ❌ 一次性倾倒全部信息：读者来不及核对，服气变成被通知。  
- ❌ 把补盲区放在最前：先讲没读过的，后面讲读过的也没人信了。  
- ✅ 分组回收，每组收尾留一个「原来如此」的落点。  
- 揭晓的人应是被情节逼到非说不可的那一个，不是作者派来的讲解者。

## 6. 自检清单

> 逐项勾选；全过才可在本章卡标 ✅。

- [ ] 每条核心线索都能在正文指到具体位置（章 · 节 · 可复述的细节）  
- [ ] 无「揭晓才第一次出现」的关键证据  
- [ ] 解谜者未使用读者没见过的信息  
- [ ] 全部核心线索在揭晓段之前已登场  
- [ ] 每条红鲱鱼都有独立解释，并在正文交代了退场  
- [ ] 辅助线索与核心线索指向一致，无自相矛盾的残留  
- [ ] 时间口径、量纲口径全书一致（并入 `novel-continuity`）  
- [ ] 叙述性诡计只靠指代与视角歧义，不靠隐瞒真值  
- [ ] 最后一次公平提示落在揭晓段之前的窗口内  
- [ ] 揭晓的补充信息量未超出读者的回溯能力  
- [ ] 二读时能凭正文完整重排真相  

> 全过 → ✅ 公平性成立；任一留空 → ❌ 不得进入揭晓段。

## 7. 与工具链接线

**章前卡登记字段**（建议并入 `templates/chapter-brief.md` 的情节线与跨章索引两节）：

| 字段 | 内容 |
|------|------|
| 本节埋线 | 编号 + 级别（核心 / 辅助 / 红鲱鱼 / 氛围）+ 载体（物 / 话 / 行为） |
| 本节回收 | 编号 + 回收方式（点明 / 复用 / 推翻） |
| 读者当前可知 | 一句话：本节结束时读者能推到哪一步 |
| 本次误导 | 被引偏的方向 + 何时交代 |

**接管分工**：

- `novel-check` 维度 6（完整性）管「卡面登记 vs 正文落地」；维度 7（伏笔追踪）管埋设、回收与凭空回收；维度 3（主线对齐）判线索是否服务主线。  
- `novel-continuity` 管时间与量纲口径——不在场证明、时刻、距离、人数都归它。  
- 阈值写进 `主题/通用约束.md`（新增「推理公平性」一节）：核心线索条数区间、补充信息占比上限、红鲱鱼条数区间、最后一次提示与揭晓的距离（用比例，不写死章号）。
