# 历史考据与防穿越工艺（历史 / 架空 · 可选工具箱）

> **定位**：类型向技法参考，**非** always 强制。历史 / 架空历史项目开写前定档，写中查漏、写后回扫。
> **用这个**：需要让时代质感可信、又想把考据成本关在笼子里时。
> **不是那个**：断代史讲义、逐条引注的考订表；也不是「越考据越高级」的自我加码。
> 下文 `<朝代>` 等占位**示例仅为格式示范**，不指向任何具体朝代或作品。

## 1. 考据分级（先定档，再下笔）

先定档，再决定查什么。同一本书允许通篇一档，**不允许**同一制度一会儿严格一会儿随手。

| 档位 | 必须守住什么 | 可以自由什么 | 典型风险 |
|---|---|---|---|
| **正史向** | 纪年大势、事件因果、制度骨架、重要人物结局 | 日常起居、对白、次要人物、具体场面细节（「大事不虚、小事不拘」） | 细节写得太满，反与史料硬碰 |
| **演义向** | 器物制度不穿帮；神异只作「时人所信」，非作者认证 | 传奇化、夸张、巧合、传闻、人物性格再塑 | 传奇盖过制度，读者不信 |
| **架空向** | 自定规则先登记（见 §5），写明与真实史实不同之处 | 朝代、地理、官制、技术树整体重编 | 借真实名号却整体改写，且不登记 |

**边界**：「不拘」指未被史料钉死的空白，**不**指与史料冲突的自由；冲突处要么改，要么降为架空并登记。

## 2. 时代语防线（先查词，再谈句）

现代词混入叙述与对白，是最廉价也最致命的穿帮。按类排查，**给替换思路，不背词典**；判定口径：**这个说话人在他的时代能说出这个词吗？**

| 类别 | 常见入侵 | 替换思路 |
|---|---|---|
| 现代行政 / 军事 | 部门、项目、流程、汇报、战略、任务 | 换成当时可指认的人、文书、差事与军制用语 |
| 现代科技 / 工业 | 系统、数据、能量、效率、信息 | 改写为可观察的现象与手工动作，不点名概念 |
| 现代心理 / 医学 | 心理、潜意识、焦虑症、创伤、情绪管理 | 用身体反应、行为习惯与旁人评语替代术语 |
| 现代经济 / 金融 | 成本、投资、市场、效益、预算、资源 | 换成当时的交易动作：称银、赊欠、行情、抽成 |
| 现代度量 / 货币 / 效率 | 公里、分钟、公斤、倒计时、赶进度 | 用当时尺度、计时法与路程感；换算只留卡面 |
| 现代教育 / 文凭 | 学历、专业、毕业、培训、考核 | 换成出身、师承、举荐、考功等当时路径 |
| 网络语 / 梗 | 内卷、破防、人设、打卡、社死 | 直接删；或换成一句可落地的动作与评语 |
| 翻译腔 / 外来音译 | 「我的天」「该死」「OK」「逻辑上」 | 用当时口语层次：文白、行话、方言腔 |
| 现代身份标签 | 女权、阶层、边界感、内驱力 | 换成当时可说的身份、礼数与利害 |
| 现代法律 / 程序 | 证据链、起诉、权利、隐私、合同 | 换成当时的词讼、状纸、中保、乡约 |

**替换不掉**就当架空设定登记（§5）；**能在正文外说清**的换算，一律不进正文。

## 3. 器物与制度防线（逐项过一遍）

| 项 | 最常见穿帮点 |
|---|---|
| **衣** | 面料与染色越级、形制错代、内衣外穿、冠帽与身份不符 |
| **食** | 后世才传入的作物与做法、调味品穿越、餐具与分餐方式、酒度与酒器 |
| **住** | 家具与坐姿（垂足坐早晚有别）、窗纸与采光、取暖与排污、院落等级 |
| **行** | 脚力与出行方式、道路条件、随行人数、女眷出行的实际限制 |
| **称谓** | 自称 / 对称 / 他称错位；上下、亲疏、官民混用；后世亲属称谓提前出现 |
| **官职** | 官名与职掌错配、品级与权力不符、机构前后重叠、追赠与生前混用 |
| **科举** | 考试层级与流程错代、功名与授官的关系、内容与文体的时代差 |
| **货币** | 银钱并用的年代感、购买力失真、找零与称量方式 |
| **度量衡** | 尺寸、容量、重量、里数口径古今混用，或把换算写进正文 |
| **交通通讯** | 消息传播速度不合理、驿传与私信混同、跨地行程时间过短 |
| **医疗** | 后世医理与药名、消毒与手术概念、诊断过于现代、寿命与死因失真 |

只查**本章会出现**的部分，不全书通查；结论写进 `主题/<朝代>.md` 或 `主题/通用约束.md`，避免重复劳动。

## 4. 社会常识防线（比器物更容易露怯）

- **等级礼法**：座次、跪拜、避讳、服色与称呼的越级即失礼；写礼的**执行**，不只写条文。
- **婚姻家庭**：婚配由谁定、彩礼与嫁妆的流向、妾与婢的区别、嫡庶与继承顺序。
- **宗教与信仰**：当时人**真的信**什么；神异写成本人经验与群体共识，不写成作者的裁决。
- **法律与刑罚**：定罪靠什么、量刑的等级差、刑讯与连坐的实际存在；不套用后世程序。
- **女性 / 平民处境**：行动半径、财产与话语权、识字率的真实分布；写限制，也写限制内的手段。
- ❌ 用现代价值观直接代言历史人物内心（把当时人写成带着后世觉悟的演讲者）。
- ✅ 让人物在他的观念框架里自洽行动，冲突留给情节与读者去撞。

## 5. 架空自定规则登记（对接世界观）

架空向的每一次「与史不同」，都必须按 `.cursor/rules/04-novel-worldbuilding.mdc` §四 的字段登记，位置为 `主题/世界观.md`、`主题/哲学母题.md` 或 `主题/<概念名>.md`：

```markdown
## <概念名>
- **定义**：
- **命名寓意**：
- **来源/原理**：
- **作用/代价**：
- **感官特征**：
- **与已有概念的关系**：
- **首次出现章节**：
```

- 登记时**额外写明**：与哪条真实史实不同、不同到什么程度、是否牵动后续制度与器物；未登记的架空设定**不得**当常识使用，已登记的不得悄悄改口径，其**代价**必须持续生效。

## 6. 考据工作流（可执行）

1. **标记**：写到不确定处，就地写 `【待考】<具体问题>`，不空着、不硬编。
2. **分级**：分「影响情节」与「只影响质感」——前者必须先查清才动笔，后者可先绕过。
3. **查证**：优先一手与制度类材料，次选可靠工具书；**不**拿同类型小说当依据。
4. **回填**：结论写回朝代档 / `主题/通用约束.md`，再统一替换正文，顺手删掉 `【待考】`。
5. **语气纪律**：不确定的内容**禁止**写成确定语气；宁可模糊带过，也不编造细节冒充考据。
6. **最小可信集**（先保证这 5 类不出错，其余可缓）：**称谓**、**货币与度量**、**官制与功名**、**衣食住行的等级感**、**消息与行程的时间**。

收尾时全书 Grep `【待考】`：命中为 0 才算清账；同义漏网按 `skills/novel-plan/reference/universal-gates.md` §3 处理。

## 7. 自检清单

- [ ] 全书已定档（正史 / 演义 / 架空），且档位前后一致
- [ ] 每个现代感词汇都能解释来路，或已替换
- [ ] 度量、货币、时间的口径全章一致，换算只留在卡面
- [ ] 称谓、官职称呼与人物身份、场合相配
- [ ] 本章出现的器物不越级、不错代
- [ ] 礼法、婚配、法律、信仰按当时逻辑运行，而非后人视角
- [ ] 没有用现代价值观替历史人物代言内心
- [ ] 架空设定与真实史实冲突处已在世界观登记
- [ ] 已登记的架空规则在本章未改口径，代价仍在生效
- [ ] `【待考】` 已全部清空，同义项已回扫

## 8. 与工具链接线

- **登记**：史实骨架与自定规则进 `主题/世界观.md`，或独立 `主题/<朝代>.md`
- **章前卡**：登记「本节考据风险点」（模板 `chapter-brief.md`），把待查项挡在动笔之前
- **词表**：通用替换口径放 `主题/通用约束.md`；项目自定黑名单只进 `.cursorGrowth/`
- **检查**：漏网 / 量纲维度由 `novel-check` 接管，术语与单位按同义回扫处理
- **一致性**：跨章口径漂移由 `novel-continuity` 负责
