# 力量体系与升级工艺（仙侠 / 玄幻 · 可选工具箱）

> **定位**：**可选** reference，服务于仙侠 / 玄幻 / 修真 / 系统流 / 异能等**有层级成长**的类型；无层级设定的项目不必套用。  
> **用这个**：要把「境界 / 等级」设计成**可校验、可闭合、不通胀**的体系时。  
> **不是那个**：越强越好的数值表；替读者爽到底的无代价碾压；把层级名当卖点堆砌。

## 1. 体系三要素（强制闭合）

任何层级、任何新能力，必须三项齐备，缺一项即视为设定漏洞：

| 要素 | 要回答的问题 | 缺了会怎样 |
|------|--------------|------------|
| **层级** | 阶梯怎么分？瓶颈在哪？ | 升级无门槛，读者失去预期 |
| **获取** | 靠什么变强（资源 / 领悟 / 传承 / 系统 / 时间）？ | 力量来源随意，努力与回报脱钩 |
| **代价** | 变强付出什么（寿命 / 心智 / 关系 / 资源 / 风险）？ | 退化为无代价碾压（`00-novel-values.mdc`） |

> 三要素**不可事后补**：新能力登场前先落进 `主题/世界观.md`。

## 2. 境界 / 等级表模板

复制进 `主题/世界观.md`；体系庞大时可独立成 `主题/<体系>.md`。

| 层级名 | 能力边界 | 瓶颈条件 | 代价 | 首次出现位置 |
|--------|----------|----------|------|--------------|
| `<基层级>` | 一句话：能做什么、做不到什么 | 何时卡住 | 每层固定成本 | 开篇段（约前 1/10） |
| `<中层级>` | 同上 | 同上 | 同上 | 前段（约 1/10–1/3） |
| `<高层级>` | 同上 | 同上 | 同上 | 中后段（约 1/3–2/3） |
| `<顶层>` | 全书上限，少用 | 同上 | 同上 | 收束段（后 1/3） |

> 上表层级名为**占位示例**，项目自定命名；命名须能在文本内自解释，勿堆生僻字。

两条硬规则：

- **压制关系**：上一层必须能稳定压制下一层。
- **越级例外**：越级取胜必须由**代价**支撑（自损 / 一次性资源 / 地利 / 情报差），且事后留下后果。❌ 靠情绪喊口号越级。

## 3. 金手指 / 系统边界

金手指（特殊能力 / 系统 / 传承）是类型向的期待引擎，边界要先于效果落纸：

- **上限**：最强只能做到什么？写死。
- **冷却 / 成本**：身体、精神、资源、时间四类成本至少各占其一。
- **触发条件**：主动 / 被动 / 情境限定？不能随叫随到。
- **禁止无代价碾压**：见 `skills/novel-plot/reference/reader-rewards.md` §6 红线。
- **可预期 ＞ 越强**：读者清楚「何时能用、能用到什么程度」时，兑现才痛快。

## 4. 升级节奏与兑现

升级 = 一次情绪兑现，不是数值 +1：

```
压抑 → 触发 → 释放 → 余韵（旁观反应 / 身份变化 / 新麻烦）
```

- **叙事密度口径**（用比例，不用章号）：小兑现每章 ≥ 1；中/大升级落在主线阶段的**后 1/3 至收束段**，两次大升级之间至少隔 1 个完整阶段的铺垫。
- 升级前**先压**：渴望、受挫、被低估；平路连续约 3 个章节单元无兑现即视为节奏风险。
- 升级**同时**给新麻烦：新层级 = 新对手、新责任、新代价，否则只是膨胀。
- 长线铺垫穿插小兑现；忌把大升级挤在结尾一次性发放。

## 5. 力量通胀防治（重点）

| 症状 | 表现 | 处方 |
|------|------|------|
| **敌人无意义贬值** | 昔日强敌沦为路边杂兵 | 让旧敌同步成长，或转为盟友 / 制度性对手 |
| **旧能力作废** | 新招一出，前文招式再无用 | 组合与克制关系；旧能力在新层级换用法 |
| **数字通胀** | 数值、倍数、年限不断加零 | 用**边界**替代数值：能做什么 ＞ 有多少 |
| **地图刷新式换场** | 换地图即换全套层级，前文归零 | 层级全界通用；新地图只是同一体系的新区域 |
| **读者不再紧张** | 出手即知结果，悬念消失 | 提高代价与信息差；胜负取决于选择而非等级 |

> 自查口径：若某个新层级逼得作者**作废**前文一半设定，那不是升级，是通胀。

## 6. 资源与宗门经济

力量必须有物质基础，否则层级只是空名：

- **稀缺资源**：明确产地、产量、单位（计量口径进 `主题/通用约束.md`）。
- **势力控制**：谁垄断开采 / 分配 / 认证？宗门、家族、行会、官方各占哪一环。
- **冲突生成**：把「获得资源」写成冲突链——稀缺 → 争抢 → 站队 → 背叛 / 交易。
- **流通规则**：资源能否交易、继承、掠夺、伪造？规则本身即剧情。

## 7. 与世界观闭合的对接

- 新概念按 `.cursor/rules/04-novel-worldbuilding.mdc` §四 注册七字段：定义 / 命名寓意 / 来源原理 / 作用代价 / 感官特征 / 与已有概念的关系 / 首次出现章节。
- 力量体系归**物理层 + 社会层**；其元规则归哲学层，不得用物理层解释哲学层（同规则 §一）。
- **感官特征**要落到身体：冷热、疼痛、气味、声响，不靠光效堆砌。
- 与 `主题/哲学母题.md` 不矛盾：层级观应映射母题，而非另立一套价值观。

## 8. 自检清单

- [ ] 每个层级的能力边界都能**一句话说清**
- [ ] 同层级战斗结果**可预测**（胜负取决于选择 / 资源 / 情报，而非随机）
- [ ] 上一层能稳定压制下一层；每次越级都有代价与后果
- [ ] 每个新能力三要素齐备（层级 / 获取 / 代价）
- [ ] 金手指有上限、冷却、触发条件
- [ ] 层级不随地图刷新而重置
- [ ] 稀缺资源有明确计量口径与掌控势力
- [ ] 全书层级总数可控，顶层后置且少用
- [ ] 升级之间有压抑与铺垫，不是连续发奖
- [ ] 新概念已按 §四 注册，且与母题不矛盾

## 9. 与工具链接线

- **落点**：写进 `主题/世界观.md`；体系庞大时独立成 `主题/<体系>.md`，并在总览留指针。
- **章前卡**：在 `.cursor/templates/chapter-brief.md` 对应位置登记「本节能力使用与代价」一行。
- **检查**：`novel-check` 的世界观闭合与维度 5 量纲接管层级名、数值、代价一致性；单维扫描可下沉 `novel-continuity`。
- **阈值**：层级名、资源计量单位、代价口径等固化项进 `主题/通用约束.md`，避免各章各写一套。
- **改名 / 新增层级**：先改 `主题/世界观.md`，再回扫全书旧称。
