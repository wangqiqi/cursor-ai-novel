# 感情线推进工艺（言情 · 可选工具箱）

> **定位**：类型向技法参考，**非** always 强制全文套用；强制底线在 `rules/02-novel-plot-design.mdc` 与 `00-novel-values.mdc`。  
> **用这个**：设计一段关系从相遇走到并肩，或诊断「感情线原地不动 / 只会撒糖」时。  
> **不是那个**：按固定章号排定的甜虐日历、性别角色分工模板、取向偏好站队。

## 1. 双引擎：Want 与 Need

双方各持一套驱动力，且**不可重合**：

| | **Want（表层目标）** | **Need（缺口）** |
|---|---|---|
| 定义 | 人物自己说得出的诉求（得到、留住、赢过、逃离） | 人物说不出口、也不自知的匮乏（被看见、被允许软弱、被信任） |
| 作用 | 提供行动的**理由**，可被拒绝、可被交易 | 提供关系的**必然性**：只有对方能补；写进人物卡缺口行（见 `novel-character`） |

关系推进的正解是：**Want 相撞 → Need 显形**。撞得越具体，显形越可信。

- ✅ 一方想拿到那份批准，另一方想保住那间铺子 → 立场对立 → 争斗中各自暴露真正的匮乏
- ✅ 关系变化必须由**事件**推动：一次赴约、一次失约、一次共同损失、一次被迫同行
- ❌ 用旁白或内心独白直接宣布「他忽然明白自己是爱她的」——那是总结，不是推进

## 2. 关系推进六阶段

阶段是**功能刻度**，不是章号分区；各阶段可长可短，但不宜跳级。

| 阶段 | 双方任务 | 读者要获得的东西 | 卡住时的症状 |
|------|----------|------------------|--------------|
| **1 相遇 / 张力建立** | 建立初始立场与不对等（身份、目的、亏欠） | 一个「为什么是这两人」的理由 + 第一次摩擦 | 只剩外貌描写；换成任何两人都成立 |
| **2 靠近与试探** | 制造被迫共处；用小动作试探边界 | 甜：兑现一次小位移（改口、递物、并肩） | 只靠巧合偶遇；试探没有代价 |
| **3 拉扯与倒退** | Want 冲突升级；出现真实代价 | 虐：压抑中看见 Need 的轮廓 | 为虐而虐；倒退到原点、进度清零 |
| **4 确认** | 至少一方做出**不可撤回**的选择 | 兑现：关系状态被公开或明确 | 谁都没付出代价就「在一起」 |
| **5 外部考验** | 用外部压力检验这段关系的成本 | 紧张：确认可能被推翻 | 外部障碍与两人缺口无关，纯拖延 |
| **6 并肩 / 收束** | 双方以各自方式补上对方的 Need | 兑现 + 余韵：关系成为人物的成长结果 | 靠「从此幸福」一句话结账 |

> 六阶段是**关系状态**的刻度；每一格都必须能回答「什么事件把它推到下一格」。

## 3. 甜虐配比与节奏

- **甜 = 兑现**：关系状态有可观察的位移（不只是心情好）；**虐 = 压抑**：位移受阻，但**缺口仍在**、欲望未消失

| 项 | 建议口径 |
|---|---|
| 甜虐比 | 约 6:4 ～ 7:3（甜 ≥ 虐；悲情向可压缩甜，但不可归零） |
| 兑现跨度 | 每段压抑期内，至少一次**部分兑现**（半步位移、缓释、共处） |
| 同调上限 | 连续同调（连甜或连虐）> 约 3 章即须切换 |
| 阶段配比 | 阶段 1–2 不宜超过全书约四分之一；阶段 6 须留足收束量 |

**红线（强制）**：

- ❌ 虐不得无回收：只压不还 → 读者流失、人物沦为作者的工具
- ❌ 用失忆、意外、第三者插入反复重置进度来制造虐
- ✅ 甜要付代价（一次原谅换来一次让步），虐要留下**新信息**（更懂对方一分）

## 4. 误解机制与上限

误解是拉扯阶段的**合法燃料**，但必须自带出口。

| | 可用 | 禁写 |
|---|---|---|
| 来源 | 性格（不敢说、要脸、职责与立场、代价不对称） | 愚蠢（明摆着的证据不看、明显的台阶不下） |
| 结构 | **信息差**：知情者不在场、各握一半真相 | 作者需要冲突所以两人都不开口 |
| 出口 | 每轮误解都逼出新信息或新代价 | 一句话能说清，却无限拖延 |

**允许的最大跨度（用比例与事件数，不写章号）**：

1. 单条误解的存续不得超过全书篇幅的约四分之一
2. 同一误解连续制造的受阻事件 ≤ 3 次，第 3 次必须出现转机或反转
3. 每经历 1 个「试探—受挫—再试探」回合，误解的**内容**必须变化（从误会升级为立场冲突，或暴露新事实）
4. 若删掉误解关系仍无变化 → 说明它不是真冲突，删

## 5. 界限与同意（合规红线）

与 `00-novel-values.mdc` §3.1「性」一栏一致：自然书写情感与亲密关系；禁止色情化、物化、强迫。

- ✅ **自愿**：亲密推进须出于双方意愿，不因亏欠、职位、救命之恩而被默认交换
- ✅ **清醒**：酒醉、药物、失智、极端情绪崩溃状态下不安排亲密推进
- ✅ **可撤回**：任一方可在任何时点中止，且中止被尊重（不遭惩罚、不被叙述斥为无情）
- ✅ 权力差（师徒、上下级、年龄差、监护、恩情）须被文本**意识到**并处理其不对等，不当作天然浪漫
- ❌ 禁止把强迫、跟踪、监视、控制、囚禁、孤立包装成「深情」或「占有欲萌点」
- ❌ 禁止性化未成年角色；涉及未成年角色时不写性内容，情感线保持非性化
- ❌ 禁止以「爱」为名美化暴力、报复性羞辱、以伤害验证忠诚
- 处理不了尺度时：淡出、留白、转场，不写过程细节

## 6. 关系张力的场景工艺

张力来自**关系变化**，不来自信息倾倒（设定说明、身世大揭秘一次讲完只会泄压）。

| 手法 | 说明 | 注意 |
|------|------|------|
| **位移优先** | 一场戏结束时，关系状态必须与开场不同（可进可退） | 无位移的戏，删或并 |
| **目标互相牵制** | 同一场戏里双方各自的 Want 相撞（为对方好 vs 完成职责） | 冲突要落在具体的事上 |
| **沉默与未说出口** | 用可观察行为代替告白：改口称呼、多带一份、放慢脚步 | 不补内心解说，读者自己读出 |
| **第三方在场** | 有旁观者时只能用身份允许的方式互动，克制生成张力 | 旁观者须有功能，非围观 |
| **倒退时给新信息** | 每次退步都暴露一个新的真实动机或软肋 | 不是单纯回到原点 |

## 7. 自检清单

- [ ] 双方各有 Want 与 Need，且两者不重合
- [ ] **每次关系状态变化都能指到触发事件**（章前卡「本章关系位移」可查到对应事件）
- [ ] 当前所处阶段明确，且未跳级（未靠近先承诺、未确认先并肩）
- [ ] 本章调性（甜/虐）已登记，与相邻章不同调
- [ ] 连续同调未超过约 3 章，且每段压抑都在兑现跨度内有回收（哪怕只是半步）
- [ ] 误解源于性格或信息差；删掉误解后关系仍会变化
- [ ] 无「一句话能说清却不说」的拖延
- [ ] 亲密推进处双方自愿、清醒、可撤回，权力差被文本正视
- [ ] 关系位移由事件承担，未用旁白宣布

## 8. 与工具链接线

- **章前卡**（`.cursor/templates/chapter-brief.md`）：在元数据或情绪曲线一节增行登记「**本章关系位移**」（状态 A → 状态 B + 触发事件）与「**本章调性（甜/虐）**」
- **`novel-check`**：维度 1「角色互动」（互动是否推动情节、是否反映人物关系）接管关系推进检查；维度 6「完整性」核对章前卡登记的位移是否在正文兑现
- **`novel-character` / `novel-dialogue`**：Need 与人物卡缺口、软肋字段对齐；未说出口、克制台词与试探性对话的落地
- **阈值落库**：甜虐比、同调上限、误解跨度写入 `主题/通用约束.md`，项目值覆盖本文件默认口径；非言情主线的副线感情线同样适用，可按比例缩放
