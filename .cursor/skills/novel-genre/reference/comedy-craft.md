# 喜剧与幽默工艺（可选工具箱）

> **定位**：类型向技法参考，**非** always 强制；也可作为正剧里的调性调剂。
> **用这个**：写喜剧类型章节、设计段子与笑点密度、给沉重段落调配幽默缓冲时。
> **不是那个**：逗笑读者就算成功；也不是把网络热梗、谐音、贬损当笑料库。

## 1. 笑点的机制

笑点是**结构**，不是素材。任何笑点都能拆成一个可复述的机制；写不出机制的，多半只是自嗨。抽象示例用 `<角色>` / `<场景>` 占位。

| 机制 | 原理 | 抽象示例 |
|------|------|----------|
| **预期违背** | 让读者先建立强预期，再用合理却意外的答案替换它 | `<角色>` 反复强调自己从不迟到，结果他在 `<场景>` 里准时出现，因为前一天就没走 |
| **三段式** | 铺垫 → 铺垫 → 反转；前两段建立规律，第三段打破规律 | 前两人对 `<角色>` 的评价是「稳」「可靠」，第三人说「所以他至今没动过」 |
| **反差** | 身份/语气/处境与言行严重不匹配 | `<角色>` 用最高规格的仪式感处理一件极琐碎的事 |
| **语言游戏** | 双关、错位、官腔：语用层面的错配 | `<角色>` 用公文腔汇报一件私事；或同一句话被两个语境各取所需 |
| **处境荒诞** | 情境本身不合逻辑，人物却认真按逻辑应对 | `<场景>` 的规则荒谬，`<角色>` 一丝不苟地遵守并推演后果 |
| **节奏与留白** | 笑点由停顿兑现；说出来不如停一下 | 反转句后不解释、不补刀，直接接下一个动作 |

- 反转必须**事后合理**：读者回头能接受，只是事先没想到。
- 一次只用一到两个机制，叠太多会互相抵消；语言游戏靠**语用错位**，不靠同音字硬凑（见第 5 节）。

## 2. 笑点密度与节奏

| 口径 | 建议 |
|------|------|
| 单元密度 | 每节约 1–2 个可用笑点；喜剧向章节可上浮到 3–4 |
| 铺垫距离 | 铺垫到回收一般不超过一章；跨章回收需在前文留可见痕迹 |
| 连续上限 | 同机制连续使用约 3 次即疲劳，须换机制或换人物 |
| 留白 | 反转后留出动作/停顿，**留白比抖包袱更重要** |

- 笑点扎堆会互相稀释：读者笑过一次，第二次的阈值更高。
- 密度不是均匀铺开，而是**疏密相间**：一段松，一段紧，再松。
- 沉重情节前后的幽默要更短、更轻，只作换气，不作表演。
- 通篇同一个笑点结构 = 读者提前预判 = 全部失效。

## 3. 幽默不破坏基调

正剧与悲剧里的幽默是**工具**，不是休息区。

| 用法 | 作用 | 注意 |
|------|------|------|
| **缓解张力** | 在高强度段落之间换气 | 只降半档，不归零；别把刚建立的压迫感全泄掉 |
| **暴露人物** | 人在放松或自嘲时露底 | 笑点要落在人物缺陷上，不落在情节严肃性上 |
| **反衬沉重** | 越日常的笑，越显后面的断裂 | 反衬需要落差，落差靠前文铺垫 |

- ❌ 在情绪高点用玩笑拆台：读者刚被推到峰值，一句调侃立刻把张力清零。
- ❌ 用幽默替人物逃避该承担的后果。
- ✅ 让幽默**服务于**基调：知道自己在为什么铺垫，再决定要不要笑。

## 4. 人物喜剧 vs 事件喜剧

| | 人物喜剧 | 事件喜剧 |
|---|---|---|
| 来源 | 性格缺陷、认知偏差、执念 | 巧合、误会、信息错位 |
| 寿命 | 可持续复现 | 一次性，用过即废 |
| 风险 | 缺陷沦为标签复读 | 巧合过多显假、消解严肃 |

- 配比建议：以**人物喜剧为主**（约七成），事件喜剧为辅（约三成）。
- 事件喜剧最好**由人物缺陷引发**，而不是天降巧合：误会是人造成的，才可回收。
- 人物喜剧要允许成长：同一个缺陷在不同阶段应产生不同后果；事件喜剧用完要留下痕迹（关系变化、信息更新），否则只是噪音。

## 5. 避雷清单

- ❌ 嘲笑弱者、身体、外貌、疾病、身份、口音、阶层
- ❌ 刻板印象当笑料（性别、地域、职业、族群）
- ❌ 网络烂梗：时效短、易过期，且极易与正文语言冲突
- ❌ 谐音硬凑：为押一个音牺牲语义与人物口吻
- ❌ 靠降智取笑：让 `<角色>` 突然变蠢来制造笑点，破坏人设与读者信任
- ❌ 与 `00-novel-values.mdc` 冲突的内容：美化禁区行为、以羞辱为乐等
- ✅ 安全区：自嘲、身份反差、语用错位、处境荒诞、聪明人的失误

## 6. 与「AI 八股」的交互

幽默最怕模板化。AI 式「伪幽默」的特征句式：

| 特征 | 表现 |
|------|------|
| 包袱预告 | 先声明「接下来这一幕很滑稽」，再叙述 |
| 解释笑点 | 反转后补一句说明为什么好笑 |
| 形容词代替结构 | 「搞笑的是」「令人忍俊不禁」直接下结论 |
| 堆梗不建预期 | 连甩俏皮话，但无铺垫、无回收 |
| 整齐排比 | 三段式被写成工整排比，规律太显眼，反转失效 |
| 万能吐槽腔 | 所有人物同一副吐槽口吻，人物声线趋同 |

处置方向见 `01-novel-language.mdc`；扫描与改稿交由 `novel-line-scanner` / `novel-line-rewriter`。

## 7. 自检清单

- ✅ 每个笑点都能指出机制（预期违背 / 三段式 / 反差 / 语言游戏 / 处境荒诞 / 留白）
- ✅ 每个笑点都能指出铺垫在哪、回收在哪
- ✅ 反转事后合理，不是靠巧合硬掰
- ✅ 不靠贬损取笑（弱者、身体、身份、刻板印象均不涉及）
- ✅ 没有网络烂梗与硬凑谐音
- ✅ 没有为制造笑点让人物降智
- ✅ 连续笑点未超上限，机制有轮换
- ✅ 反转后有留白，没有解释笑点
- ✅ 正剧/悲剧段落中的幽默未在情绪高点拆台
- ✅ 幽默服务于人物与基调，不是为笑而笑
