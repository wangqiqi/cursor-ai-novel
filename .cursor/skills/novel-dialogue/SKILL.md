# 对白医生 · novel-dialogue

## 触发场景

- "优化对白"
- "对话太水 / 太硬"
- "修对话"
- 提交前最后一轮校对

## 输入

- 目标章节（`章节/第NN章_*.md`）
- 复用：人物卡 `主题/人物/*.md`（或 `人物/*.md`，按项目目录约定）

## 6 项硬性检查

### 1. 目标冲突

每场对话至少 2 个角色有不同目标。

❌ 两人一起感叹天气
✅ 两人讨论"是否炸冷却塔"——一个要炸，一个要保

### 2. 潜台词

至少 1/3 对白有潜台词——角色说的 ≠ 想的。

✅ "你今天气色不错"（实际："我看出你昨晚没睡"）

### 3. 角色语音

用词习惯匹配人物卡。检查：

- ❌ <角色 A> 说了 <角色 B> 风格的从句（身份不符）
- ❌ <角色 B> 用了与其背景完全不符的语体（例：非人类角色用脏话）
- ✅ 用 `主题/人物/<角色>.md` 中的“性格 / 运行特征”和“关键台词与瞬间”对照口吻、节奏与信息粒度

### 4. 节拍断句

- 单句 ≤ 20 字
- 长对话必须断行
- 不允许一段超过 200 字不分段

### 5. 动作穿插

每 3-5 句对白穿插 1 个动作/环境描写。

❌ 纯对话堆砌
✅ "他点了一下头。" + 对白 + "她的手指敲着桌面。" + 对白

### 6. 信息密度

每场对话至少推进 1 个情节点或揭示 1 个信息。

❌ 寒暄
✅ "你怎么进来的？"（揭示：他有不为人知的入口）

## 工作流

### 1. 提取章节内所有对白

按出现顺序列表，标注说话人。

### 2. 6 项检查逐条打分

| 检查项 | 得分（1-5） | 问题举例 |
|--------|------------|---------|
| 1. 目标冲突 |  |  |
| 2. 潜台词 |  |  |
| 3. 角色语音 |  |  |
| 4. 节拍断句 |  |  |
| 5. 动作穿插 |  |  |
| 6. 信息密度 |  |  |

### 3. 红色批注

- 🔴 **必须改**：影响人物一致性 / 推动力为 0 / 翻译腔
- 🟡 **建议改**：可更精准 / 潜台词未明
- 🟢 **可选改**：作者风格选择

### 4. 改后保留原句对比

```markdown
### 对话 #N（第 X 段）
**原**："你怎么在这里？"
**改**："你从哪进来的？"

**理由**：潜台词强化——从"你来了"变成"你有不为人知的入口"。
```

## 输出

- 报告写入 `.cursorGrowth/archive/YYYYMMDD_HHMMSS_对话_第NN章_审校.md`
- 同时写入 `.cursorGrowth/check/第NN章_第SS节_复盘.md`
- **🔴 铁律**：**任何对白批注 / 修改清单 / 元数据，一概不许写进 `章节/<章>/<节>.md` 正文**——正文永远是小说文稿

## 反模式（避免）

- ❌ 只挑"感觉不好"的问题
- ❌ 改完后不保留原句
- ❌ 不引用人物卡
- ❌ 把作者风格当"问题"全盘否定
