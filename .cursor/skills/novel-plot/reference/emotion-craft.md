# 情绪工艺 · 调性与节奏（可选工具箱）

> **定位**：技法参考，**非** always 强制。  
> **用这个**：定全书/章调性、设计甜虐或爆发–释放节奏时。  
> **不是那个**：单次「爽点」公式（→ `reader-rewards.md`）；平台情绪算法。

## 1. 调性 ≠ 爽点

| | 调性 | 爽点 |
|---|---|---|
| 尺度 | 全书 / 卷 / 章的「底色」 | 章内一次情绪兑现 |
| 例子 | 孤傲 · 压抑 · 暖幽默 · 冷峻讽刺 | 反差翻盘、情感爆发 |
| 缺了 | 同质化、风格漂 | 只挖坑不填 → 腻 |

章前卡可填「本章调性」一行，与情绪曲线、爽点表并列。

## 2. 情绪备忘录（创作外习惯）

生活中记下「看剧/书/热搜时剧烈波动」的情节骨架（冲突类型 + 触发物 + 释放方式），写作时改编为**有代价**的兑现，勿原样搬平台八卦。

## 3. 爆发与释放（章内节奏）

```
蓄压 → 小释放 → 再蓄 → 爆发 → 缓冲（幽默/日常/余韵）
```

| 手法 | 说明 | 注意 |
|------|------|------|
| **甜虐交织** | 甜中嵌「玻璃渣」、虐后接缓释 | 虐不导向虚无/厌世（见价值观） |
| **同向叠压** | 连续压抑抬期待 | 须在约 3 章内有兑现（见 `02`） |
| **反差落差** | 暖↔冷、希望↔断裂 | 落差服务人物弧，非为虐而虐 |

## 4. 情绪统领全篇

- scaffold / 总览宜有一句**全书情绪定位**（可与 logline 并列）
- 各章调性可偏移，但勿无预告整卷跳调（除非项目明确多调拼贴）

## 5. 红线

- ❌ 把厌世、轻生、极端利己当「高级情绪」推销
- ❌ 无铺垫的情绪过山车（人设崩）
- ✅ 共鸣来自具体欲望与障碍，不来自口号
