# 读者奖励 · 钩子与爽点（可选工具箱）

> **定位**：技法参考，**非** always 强制全文套用。强制底线在 `rules/02-novel-plot-design.mdc` 与 `00-novel-values.mdc`。  
> **用这个**：需要设计连载追读、章内情绪兑现时。  
> **不是那个**：平台追读率算法、固定「爽 70%」比例。

## 1. 钩子 ≠ 爽点

| | 钩子 | 爽点 |
|---|---|---|
| 功能 | 拉力：为什么往下看 | 释放：看完爽不爽 |
| 位置 | 多在章/节末 | 章内任意，常在转后 |
| 缺了 | 读者退出 | 只挖坑不填 → 腻 / 掉追读 |

## 2. 爽点公式

```
压抑 / 期待 → 触发 → 释放 → 余韵（旁观反应可选）
```

大爽若跨多章铺垫，中间必须穿插小爽。

## 3. 六手法（可轮换）

| 手法 | 核心快感 | 注意 |
|------|----------|------|
| **反差** | 弱↔强落差越大越痛快 | 反派态度落差往往比实力落差更重要 |
| **信息差** | 读者知底牌、对手不知 | 给足信息；对手无知要充分 |
| **打脸** | 当众否定后干净翻盘 | 宜稀缺；需围观反应放大；忌章章同质 |
| **破局** | 真绝境 + 早埋伏笔的后手 | 无伏笔的开挂会折损信任 |
| **估值** | 价值层层被低估再揭示 | 低估者身份越重，冲击越大 |
| **情感** | 守护 / 救赎 / 重逢 | 铺垫要够；爆发宜克制 |

新手可先练反差 + 打脸，再叠破局、情感。

## 4. 密度口诀（经验）

- 每章 ≥ 1 小爽；每 3–5 章 1 中/大爽
- 平路连续约 3 章无兑现 → 危险
- 类型轮换防疲劳

## 5. 钩子类型

悬念式 · 反转式 · 情绪炸弹式 · 信息投放式 —— 写进章前卡，勿事后补。

## 6. 红线（强制）

- ❌ 无代价、无限制碾压；美化禁区行为（见价值观宪法）
- ❌ 为爽强行降智 / 人设崩塌
- ✅ 有代价的释放、智斗兑现、关系推进、主题向的情感高潮
