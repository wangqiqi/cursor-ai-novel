# 自适应开篇 / 中点 / 高潮窗协议

> **定位**：`.cursor` 母版只给**比例与公式**；具体「第几章」由项目登记。  
> **禁止**：在 rules/skills 里写死「黄金三章 / 前 10 章 / 第 N 章高潮」作为强制项。  
> **项目登记**：优先 `主题/节奏窗.md`（回退 `主题/_meta/节奏窗.md`；模板见 `.cursor/templates/rhythm-window.md`）。  
> **关联**：`02-novel-plot-design.mdc` · `reader-rewards.md` · `novel-scaffold` · `novel-check`

## 1. 输入（来自最初讨论 / scaffold）

| 输入 | 来源 |
|------|------|
| **篇幅档** | Q2：短 / 中 / 长 / 史诗 |
| **颗粒度档** | `主题/通用约束.md` §1.1：A 网文 / B 出版 / C 大章·卷——**决定"章"是什么** |
| **总章数 N** | 规划总章；**按所选颗粒度档计数**；未知则用「目标字数 ÷ 预估章均字数」取整 |
| **结构** | Q5：三幕 / 起承转合 / 英雄之旅 / …（映射到幕或阶段占比） |

> ⚠️ **N 的含义随颗粒度档变化**：A 档 N 是"多少话"（可上百上千），C 档 N 是"多少个大章/卷"。
> 换档必须重算本表并更新 `主题/节奏窗.md`；`主题/总览.md` 的 N 必须同义同值。

## 2. 默认换算（项目可覆盖）

设全书计划章数为 **N**（N ≥ 1，含义见 §1 颗粒度档）。

| 窗口 | 默认公式 | 登记字段 |
|------|----------|----------|
| **开篇窗** | 章 `1 .. max(1, round(r_open × N))` | `开篇窗_起`–`开篇窗_止` |
| **中点** | 章 `round(0.50 × N)`（或第二幕中点节拍映射章） | `中点章` |
| **高潮区** | 章 `round(0.75 × N) .. N`（约后 25%，对齐第三幕） | `高潮区_起`–`高潮区_止` |

### 开篇窗占比 r_open（按篇幅档）

| 篇幅档 | r_open | 说明 |
|--------|--------|------|
| 短篇 | 0.15–0.25 | N 小，窗占比可略高 |
| 中篇 | ~0.12 | — |
| 长篇 | ~0.10 | — |
| 史诗 | ~0.08 | 可另设**卷内开篇窗**（每卷重复微缩），勿写死全书前固定章数 |

## 3. 开篇窗内必须完成（与章数无关）

在**开篇窗任一章**累计达成即可（不必挤在「前三章」）：

1. 核心设定可读  
2. 主冲突已抛出  
3. 主角形象立住  
4. ≥ 1 次情绪兑现（爽点）+ 有效钩子  

### 3.1 开篇窗内「首屏」技法（段落级 · 非死章号）

开篇窗**第一章开头若干段**（约首屏可读量）建议直接切入悬念或冲突结果，忌大段无压风景/设定说明书。  
具体段数随媒介与篇幅浮动；**禁止**把「前三段」写成 always 硬指标。

开篇窗内奖励密度**建议高于中段**；严肃向可降密度，但不可「零兑现」。

## 4. 高潮区

- 终局交锋 / 主题落点落在高潮区内，**具体章**由节拍表映射，不由母版指定  
- 高潮区可再抬奖励密度；须服从 `00-novel-values`（有代价的兑现）

## 5. 演算示例（非硬编码）

假想 **长篇 N=40**，r_open=0.10：

| 窗口 | 演算结果（仅示例） |
|------|-------------------|
| 开篇窗 | 1–4 |
| 中点 | ~20 |
| 高潮区 | 30–40 |

假想 **短篇 N=8**，r_open=0.25：开篇窗 1–2；中点 ~4；高潮区 6–8。

> 换 N 或篇幅档后必须重算并写回 `节奏窗.md`。

## 6. Agent 行为

1. 写章 / check 前：Read `主题/节奏窗.md`（无则 `_meta/`；若皆无则按总览 Q2+N 生成草稿并请用户确认）  
2. 章前卡勾选「是否落在开篇窗 / 高潮区」时，用**登记起止章**判断，不用母版死数字  
3. 禁止把本示例表复制进 rule 当强制清单

## 7. 与三幕及其他结构的关系

| 结构 | 如何映射窗口 |
|------|----------------|
| **三幕** | 开篇窗 ⊆ 第一幕前段；中点 ≈ 第二幕中点；高潮区 ≈ 第三幕 |
| **起承转合** | 开篇窗 ⊆「起」；中点落在「转」附近；高潮区 ⊆「合」前段至终 |
| **英雄之旅** | 开篇窗 ⊆ 日常世界+召唤；中点 ≈ 磨难中段；高潮区 ⊆ 归来/终极试炼 |
| **自由 / 多线** | 仍用 N×比例定窗；各线可自备微缩开篇窗，写入节奏窗备注 |

三幕占比参考（可被项目覆盖）：

| 三幕 | 约占全书 | 与窗口 |
|------|----------|--------|
| 第一幕 | ~25% | 开篇窗通常短于整幕 |
| 第二幕 | ~50% | 含中点 |
| 第三幕 | ~25% | ≈ 高潮区默认落点 |
