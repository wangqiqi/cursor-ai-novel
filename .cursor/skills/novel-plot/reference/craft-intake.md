# 工艺摄入 · 扫榜与拆文（可选）

> **定位**：学习他人技法的**方法**页；产出默认进 Growth learn，不改母版除非授权。  
> **用这个**：新手扫榜、定向拆一本热门/经典时。  
> **不是那个**：抄袭情节/人设/独特设定；把单本爆款当万能公式。

## 1. 原则

人写不出认知以外的结构手感——用**写作者眼光**读，不消费式刷。

## 2. 拆解清单（每本限 1 页笔记）

| 维 | 记什么 |
|----|--------|
| 开篇首屏 | 冲突/悬念如何进场（段级，非死章号） |
| 钩子与兑现 | 章末拉力 + 章内释放是否配对 |
| 人物欲望 | 主角要什么、怕什么、如何变 |
| 情绪调性 | 全书底色 + 甜虐/爆发释放节奏 |
| 类型招式 | 金手指边界、反套路拧在哪（可选） |

笔记路径建议：`.cursorGrowth/learn/craft-notes/<书名或平台简称>.md`
