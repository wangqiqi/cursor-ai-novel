# 类型 / 商业钩子箱（可选）

> **定位**：**可选** reference，默认不强制严肃向项目套用。  
> **用这个**：网文/类型向需要「代入 · 金手指 · 酣畅 · 反套路」时。  
> **不是那个**：无代价开挂圣经；把「爆款」写成 always rule。

## 1. 核心三要素（类型向经验）

| 要素 | 含义 | 本仓约束 |
|------|------|----------|
| **代入感** | 主角处境可读、欲望清楚、读者愿跟 | 对齐人物卡欲望/弱点；见 `03` |
| **金手指** | 特殊能力/机遇，抬期待、破平淡 | **必须有代价/限制**；禁无限制碾压（`00-novel-values` · `reader-rewards`） |
| **酣畅感** | 命运大波折、首尾大落差；主线简单、细节复杂 | 冲突升级 + 有兑现；勿纯堆奇遇 |

## 2. 反套路 / 反向操作

- 在熟悉类型期待上**拧一处**：诗意↔雄浑、好人表象下的伤害逻辑、反派侧的可理解动机（**不**把反派写成价值楷模）
- brainstorm 阶段可用「类型反转」（已有）；定稿前过价值观三问

## 3. 金手指使用节奏

- 平淡或期待跌破阈值时**可**动用，使人生再起波澜  
- ❌ 章章开挂、无伏笔破局、降智对手成全主角  
- ✅ 早埋伏笔（见伏笔板）；能力有边界；兑现有代价

## 4. 「瞎写」备注（可选心态）

掌握逻辑后可偶发破格灵感；**入库前**须过连续性与价值观。灵感 ≠ 免连续性检查。
