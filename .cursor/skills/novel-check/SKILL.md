# 自洽性 & 完整性主控检查 · novel-check

> **"一切设定都是约束。一切约束都是为了让故事自洽。"**
> 这是 novel-continuity 的**主控升级版** —— 把分散的检查整合为统一的"自洽性闸门"。

## 触发场景

- "check 一下"
- "自洽性检查"
- "完整性检查"
- "是不是符合最初设定"
- "会不会跟前面的设定矛盾"
- **任何一章写完后的强制动作**
- **提交 / 发布前的最后闸门**

## 与 novel-continuity 的关系

| 维度 | `novel-continuity` | `novel-check`（本技能） |
|------|--------------------|------------------------|
| **定位** | 底层执行（细节检查） | **顶层主控**（多 agent 调度） |
| **范围** | 单维度深扫（时间/地理/道具/伏笔） | **8 维度聚合**（互动/角色/主线/价值观/时间/完整/伏笔/哲学） |
| **深度** | 细致逐条 | **调度其他 agent 深度处理** |
| **结论** | 冲突清单 | **三档决策：✅ 通过 / 🟡 有条件通过 / 🔴 不通过** |
| **关系** | 被 check 调用 | 调用 continuity + character-coach + architect + world-keeper + reader-simulator |

> 简单说：**`novel-continuity` 是工具，`novel-check` 是工作流**。

## 8 大检查维度

### 维度 1 · 角色互动

**核心问题**：本场景/本章的人物互动是否有意义？是否符合关系矩阵？

检查项：

- [ ] 互动是否推动了情节？**（不是为互动而互动）**
- [ ] 互动是否反映了人物关系？**（参考 `主题/人物关系矩阵.md`）**
- [ ] 是否有"沉默的互动"被错过？**（如：隔墙有耳、擦肩而过）**
- [ ] 互动权力关系是否清晰？**（谁主导、谁配合、谁对抗）**
- [ ] 是否每个登场角色都有"出场目的"？**（路人甲也要有功能）**

### 维度 2 · 角色一致性

**核心问题**：角色行为是否符合最初的人物卡设定？

检查项：

- [ ] 性格前后一致
- [ ] 关键台词与关键时刻语言风格匹配（对照人物卡第 6 节 + 第 4 节）
- [ ] 核心命题回指并解释本章的转向/坚持（不是只制造对立）
- [ ] 弧光方向正确（起点/中段/终点与关键台词/瞬间覆盖一致）
- [ ] **特别检查**：主角光环、角色工具化、性格突变

### 维度 3 · 主线对齐

**核心问题**：本章是否在推进 `主题/<核心大纲>.md`（如 `主线剧情.md`）的剧情节点？

检查项：

- [ ] 本章对应大纲中的哪个节点？
- [ ] 推进了哪个节点的哪一部分？
- [ ] 是否偏离了主线轨道？
- [ ] 已规划节点完成情况：✅
- [ ] 未达节点推进情况：⏳
- [ ] 三幕比例是否失衡？

### 维度 4 · 价值观对齐（母题落点）

**核心问题**：本章是否扣紧了母题和冲突轴？

检查项：

- [ ] 对应 `主题/哲学母题.md` 中哪个母题？
- [ ] 推进了哪个冲突轴？**（参考 `主题/主要冲突点.md`）**
- [ ] 是否在说教？**（Show, don't tell）**
- [ ] 关键意象是否到位？
- [ ] **特别检查**：是否有"画蛇添足"的母题**（如：硬塞一个明显不属于自己的母题）**

### 维度 5 · 时间一致性

**核心问题**：本章的时间标记是否与前后章连贯？

检查项：

- [ ] 接续上一章结尾的时间点
- [ ] 季节/天气/昼夜标记一致
- [ ] 角色年龄/状态变化合理
- [ ] **本章时间跨度**与叙事密度匹配
- [ ] **特别检查**：非人类角色（AI / 异族）视角的时间精度（用其视角特有的时间单位或异常描述）

### 维度 6 · 完整性（章前卡 vs 正文）

**核心问题**：章前卡上写的，本章都写了吗？

检查项：

- [ ] 章节目标（≤ 3 个）全部达成？
- [ ] 场景序列（2-4 个）全部出现？
- [ ] 关键道具/意象全部到位？
- [ ] **本章爽点**已在章前卡登记且正文有兑现？（≥ 1；类型轮换优先）
- [ ] **章末钩子**已设置？（类型 + 钩子句；禁止平收）
- [ ] 相对上章：冲突有升级或转化？（非同强度复读）
- [ ] **节奏窗**：若存在 `主题/节奏窗.md`（或 `_meta/` 回退），本章是否标注开篇窗/高潮区？开篇窗内是否已有设定+冲突+主角+兑现？（用项目登记章号，**禁止**用母版死章号判断）
- [ ] 主题推进到位？
- [ ] 无「无代价碾压式爽感」踩 `00-novel-values`？

### 维度 7 · 伏笔追踪

**核心问题**：本章埋设/回收的伏笔是否完整记录？

检查项：

- [ ] **本章回收**：哪些伏笔在伏笔板中标记为回收？（优先 `主题/伏笔板.md`）
- [ ] **本章埋设**：哪些新伏笔已登记？
- [ ] **凭空回收**：是否有"前文未埋"的回收？
- [ ] **超期未收**：是否有 > 10 章未回收的伏笔？
- [ ] **新概念注册**：引入的新概念是否在 `主题/世界观.md` 注册？

### 维度 8 · 哲学深度（针对严肃文学/哲思类）

**核心问题**：本章是否体现了应有的哲学维度？

检查项（如作品涉及哲学母题）：

- [ ] 是否推进了哲学暗线？**（不显性化）**
- [ ] 主要冲突轴中哪个被推进？
- [ ] 关键警示是否遵守？**（如：不要让非人类角色直接"悟道"）**
- [ ] 哲学不是"说"出来，而是"演"出来？

## 工作流

### 阶段 1：准备（Prepare）

```markdown
1. 读取目标章节（`章节/第NN章_*.md`）
2. 读取章前卡（优先 `主题/章节卡/`，回退 `主题/_meta/第NN章_章前卡.md`）
3. 扫描项目已有资产：
   - `主题/世界观.md`
   - `主题/<核心大纲>.md`（如 `主线剧情.md`）
   - `主题/哲学母题.md`
   - `主题/主要冲突点.md`
   - `主题/人物关系矩阵.md`
   - `主题/人物/*.md`（涉及的所有人物）
   - `主题/<设定相关>.md`（涉及的所有设定，如 `<概念>.md`、`<地点>.md` 等）
   - `主题/伏笔板.md`（回退 `主题/_meta/伏笔板.md`）
```

### 阶段 2：调度（Dispatch）

按需调度以下 agent / skill：

| 维度 | 调用 | 何时调用 |
|------|------|---------|
| 1 · 互动 | `novel-character-coach` | 必有 |
| 2 · 角色 | `novel-character-coach` | 必有 |
| 3 · 主线 | `novel-architect` | 必有 |
| 4 · 价值观 | `novel-world-keeper`（哲学层） | 必有 |
| 5 · 时间 | `novel-continuity-sleuth` | 必有 |
| 6 · 完整 | 内置 checklist | 必有 |
| 7 · 伏笔 | `novel-continuity-sleuth` | 必有 |
| 8 · 哲学 | `novel-world-keeper` + `novel-reader-simulator` | 如涉及哲学母题 |

每个 agent 单独生成报告：

```
.cursorGrowth/archive/YYYYMMDD_HHMMSS_check_第NN章_<维度>_<agent>.md
```

### 阶段 3：聚合（Aggregate）

聚合所有 agent 报告，生成**主报告**（当前活跃）：

`.cursorGrowth/check/第NN章_ncheck.md`

闭合 sprint 后迁：

`.cursorGrowth/archive/YYYYMMDD_HHMMSS_check_第NN章_主报告.md`

**禁止**写入 `主题/` 或 `章节/`。

格式：

```markdown
# 自洽性 & 完整性检查 · 第 NN 章 · YYYY-MM-DD

## 一、综合结论

🔴 不通过 / 🟡 有条件通过 / ✅ 通过

## 二、8 维度评分

| # | 维度 | 评分（1-10） | 关键问题 |
|---|------|-------------|---------|
| 1 | 角色互动 | 8 | …… |
| 2 | 角色一致性 | 9 | …… |
| 3 | 主线对齐 | 7 | …… |
| 4 | 价值观对齐 | 8 | …… |
| 5 | 时间一致性 | 10 | …… |
| 6 | 完整性 | 6 | 章前卡目标 3 未达成 |
| 7 | 伏笔追踪 | 7 | 第 X 章伏笔未登记 |
| 8 | 哲学深度 | 9 | …… |

## 三、🔴 必须改

（聚合各 agent 的红色项）

## 四、🟡 建议改

## 五、🟢 可选改

## 六、下一步

- [ ] 必须改完成后再触发本 check
- [ ] 或进入 `/nfix` 修订流水线
```

### 阶段 4：决策（Decide）

根据综合评分，自动生成三档决策：

| 综合分 | 决策 | 含义 |
|--------|------|------|
| **平均 ≥ 8** | ✅ **通过** | 可进入下一章 / 可归档 |
| **平均 6-7.9** | 🟡 **有条件通过** | 必须先修 🔴 项 |
| **平均 < 6** 或 任意维度 ≤ 4 | 🔴 **不通过** | 必须重写或大改 |

### 阶段 5：归档（Archive）

- 主报告归档：`.cursorGrowth/archive/YYYYMMDD_HHMMSS_check_第NN章_主报告.md`
- 子报告归档：每个 agent 一份
- CHANGELOG 追加（如果决策为 🔴 或 🟡）

## 输出位置

## 与 novel-continuity 的边界

**novel-check 调用 novel-continuity，但反过来不调用。**

具体边界：

| 检查项 | 由谁负责 |
|--------|---------|
| 时间标记一致性 | `novel-continuity`（被 check 调用） |
| 地理距离合理性 | `novel-continuity` |
| 道具归属追踪 | `novel-continuity` |
| 伏笔板 | `novel-continuity`（被 check 调用） |
| **角色互动** | `novel-check` 直接负责 |
| **角色一致性 vs 人物卡** | `novel-check` 调度 `character-coach` |
| **主线对齐** | `novel-check` 调度 `architect` |
| **价值观对齐** | `novel-check` 调度 `world-keeper` |
| **哲学深度** | `novel-check` 调度 `world-keeper` + `reader-simulator` |

## 反模式（避免）

- ❌ 跳过 8 维度直接做"我觉得"
- ❌ 只看文字不看章前卡
- ❌ 不调 agent 自己一个人查（漏维度）
- ❌ 不出三档决策（无法定下一步）
- ❌ 哲学类作品跳过维度 8
- ❌ 不归档（无法回溯）

## 关联

- **下游**：用户决策后调用 `/nfix` 进入修订流水线
- **上游**：任何写完章节后必触发；用户主动 `/ncheck` 也触发
- **规则引用**：`.cursor/rules/00-novel-meta.mdc`、`.cursor/rules/03-novel-character.mdc`、`.cursor/rules/04-novel-worldbuilding.mdc`
- **命令**：`.cursor/commands/ncheck.md`（一键触发）
- **Agent**：`.cursor/agents/novel-check-master.agent.md`（执行专家）
