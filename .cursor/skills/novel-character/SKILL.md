# 人物圣经 · novel-character

## 触发场景

- 新增角色（主角/配角/反派/导师/镜像）
- 已有角色卡片，要补全字段
- 角色行为前后矛盾，需要校准
- 需要校准“关键台词与瞬间”以保证人物一致性

## 输入

- 角色名 + 1-2 句描述
- 复用：现有 `主题/人物/*.md`（如项目用 `主题/人物/` 目录），或 `人物/*.md`（识别为已有并扩展）

## 11 节模板（强制）

详见 `.cursor/templates/character-card.md`：

0. **一句话定义**
1. **核心命题**
2. **基本档案**
3. **外貌与行为**（AI：行为层）
4. **性格 / 运行特征**（AI：算法层 + 行为层）
5. **角色弧光**
6. **关键台词与瞬间**
7. **与他人关系**（表格）
8. **Memorable Moment（3 个跨章）**
9. **章节登场索引**
10. **哲学 / 母题维度（链接 / 速览）**

## 工作流

### 1. 提取角色基本盘

- **身份** + **核心功能**（主角/对手/导师/镜像/小丑）
- **一句话定位**：这个角色在小说中扮演什么？
- **核心命题候选**：一句话写出“这个角色追问什么 / 追问到什么悖论”

### 2. 核心命题落地（核心）

- **核心命题**是一句可被记住的“追问/悖论”
- 它必须能解释：角色为什么行动、为什么坚持、为什么崩塌或转向
- 核心命题 → 章节级回响：在第 6 节关键台词与第 5 节角色弧光中形成闭环（起点 / 中段 / 终点分别对应）

### 3. 弧光类型（4 选 1）

| 类型 | 适用 | 例 |
|------|------|-----|
| **正向** | 主角 | <主角>（缺陷→完整） |
| **负向** | 反派 | 堕落者 |
| **平面** | 旁观者/导师 | 部分配角 |
| **逆向** | 觉醒型 | 非人类/觉醒角色（看似完整→真实破碎） |

### 4. 关键台词与瞬间一致性（强制）

- 至少 5 条关键台词（对应 6.1）
- 至少 3 个关键时刻（对应 6.2）
- 每条台词/时刻都必须回指核心命题，并推进弧光（起点 / 中段 / 终点至少各覆盖一次）

### 5. 对话独特性

≥ 3 条关键台词的风格必须可区分，让读者“用耳朵听见这个人”（不要只是重复口癖，要有信息粒度差异）。

> **边界**：此处只做「人物卡级」的风格定型。**逐句对白打磨**（目标冲突 / 潜台词 / 断句 / 动作穿插）走 `novel-dialogue`。

### 6. 与已有角色的关系矩阵

- **≥3 个具名人物时，必须创建 / 更新** `主题/人物关系矩阵.md`（首次由本技能建立；这是 `novel-check` 维度 1 的输入）
- 矩阵至少标注：盟友、对手、镜像、师承；每人一行 × 每人一列的关系类型
- 已有矩阵则**补行补列**，不覆盖他人条目

## 输出

- 人物卡：写入 `主题/人物/<姓名>.md`，格式套用 `.cursor/templates/character-card.md`
- 关系矩阵（≥3 人物时）：`主题/人物关系矩阵.md`

## 特殊角色处理

### 非人类类角色（AI / 异族 / 神性）

- 必须有"认知边界"小节（能理解什么、无法理解什么）
- 觉醒时刻需要**物理层 + 特有视角层**双重描写
- 对话要有"逻辑链 / 仪式语 / 系统语"特征 + 偶尔"无法归类输出"

### 群体类角色（组织 / 教派 / 居民）

- 用"典型代表 + 群体行为模式"双轨
- 必须有内部分歧
- **归属边界**：**组织/派系本身**作为设定条目 → `novel-world`（`主题/<组织>.md`，`templates/faction-card.md`）；**群体作为角色弧光**（代理人物、群体心理转变）→ 本技能。

## 反模式（避免）

- ❌ 核心命题模糊或无法解释角色行动 / 坚持 / 转向
- ❌ 关键台词与瞬间不能回指核心命题（只抒情不推进）
- ❌ 角色弧光缺少起点 / 中段 / 终点的明确对应
- ❌ Memorable Moment 不跨章或缺少对人物弧光的意义
- ❌ 角色关系表与关键台词/瞬间冲突
- ❌ 哲学 / 母题维度缺失或无法映射核心命题
