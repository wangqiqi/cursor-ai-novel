# 绵密缠绕（福克纳 / 普鲁斯特 / 金宇澄）· 风格原型

> **定位**：风格原型参考，**非**强制；选定后由 `主题/风格档.md` 落成本书契约。
> **用这个**：想写长句缠绕、时间折叠、内心戏稠密，想用一句话装下一段回忆时。
> **不是那个**：不是「句子越长越好」，也不是堆砌从句、套嵌到读者读不懂；不靠长句冒充深刻。

## 1. 原型签名

一句话：**叙述者的气息长到能把几个时间层折进同一句，让回忆与此刻共用一套语法，而读者始终找得到主语。**

| 判据 | 表现 | 反证 |
|------|------|------|
| **长而不失骨干** | 长句内部有主谓骨架与呼吸节拍，一口气可读完，主语随时可追踪 | 从句一路套嵌，读到句末已不知谁在做 |
| **时间在句内折叠** | 现在的动作里嵌着过去的片段，靠语法层融合，不另起一段交代前情 | 回忆与现实分成两块，靠标记硬切开 |
| **修饰都在承重** | 定语、插入语、并列分句携带新的感知、判断或记忆 | 删掉全部修饰，信息与情绪毫无变化 |

## 2. 8 轴要点（怎么做到）

数值真源：`.cursor/tools/data/style-archetypes.json` 的 `archetypes["dense-interwoven"].targets`（表内为关键几项内联，完整轴以该文件为准；轴的名称与单位见其 `_axes`）。

| 轴 | 本原型区间 | 怎么做到 |
|----|-----------|----------|
| 平均句长 | 30–48 字/句 | 一个句子同时推进动作、感知与判断。分句承接递进与补充，而不是把一件事说完就落句号 |
| 句长标准差 | 14–26 | 每三到四个长句之后放一个短句落地；全篇一样长＝没有落点，标准差反而跌出区间 |
| 逗号密度 | 90–145 / 千字 | 逗号按气息落，长句内部至少两处停顿；句号只留给真正的停与转 |
| 破折号 | 2–7 / 千字 | 用于插入与自我修正，一次一句最多一个；不能替代逗号做主要呼吸 |
| 平均段长 | 150–420 字 | 一段＝一个完整的意识单元。注意力没转移就不分段，不按字数切碎 |
| 比喻密度 | 1.5–3.0 / 百字 | 比喻少而准，一句里不叠两个明喻；通感优先于明喻 |
| 通感句占比 | 5–12% | 同一句里让两个感官通道交汇（气味带出声音，触感带出温度），不整段通感 |
| 心理句占比 | 20–35% | 意识流动是本位。但每段意识都要落回身体与手上动作作出口 |
| 内耗:外化 | 2.5–6.0 | 允许内耗远多于外化，但比值不能无限大：一段内至少一次外化 |
| 对话句占比 | 12–30% | 对白被吸收进叙述，多用间接引语与半直接引语，让它长在长句里 |
| 感叹号密度 | 0–3 / 千字 | 近乎不用。情绪强度靠句子的缠绕程度调节，不靠标点升级 |
| 显性时间标记 | 8–20 / 千字 | 「那年/后来/等到/这时候」是句内跳跃的锚；够用即可，堆多了时间轴浮在表面 |
| 议论句占比 | 3–10% | 叙述者可以出面判断与总结，但只在一段收束处点一句 |
| 感官优先 | 嗅觉 / 听觉 | 先写闻到什么、听见什么，视觉退居其后；非视觉通道每节至少两个 |
| 解释连接词 | 4–9 / 千字 | 「因为/所以/原来/其实」取中低；折叠本身要自明，少解释 |
| 省略号密度 | 1–5 / 千字 | 低位使用。省略号是断气，本原型要的是不断气 |
| 口语标记密度 | 2–10 / 千字 | 口语词作长句里的换气口，不作调味料；用多了缠绕会散成闲聊 |
| 专名术语密度 | 0–5 / 千字 | 思辨由具体物象承载，概念词让位；学术腔一起删 |
| 元叙事标记 | 0–2 / 千字 | 不引档案、注释、书中书来制造智性；绵密靠句法，不靠文本装置 |

- 第一人称句占比 0–80%：几乎不设限，贴身第三人称与第一人称都可承载绵密。
- 情绪-句式映射（与 `templates/style-profile.md` §六 对齐）：悲伤 → 句子更长、从句更深，逗号绵密；犹疑 → 插入语与自我修正增多；愤怒 → 缠绕突然收成短句，用一次断裂代替感叹号。

## 3. 可操作技法

1. **并列从句承载同一瞬间的多重感知**：一句话里让听觉、嗅觉、触觉同时到场，用并列串成一次完整的知觉，而不是依次报告。
2. **时间在从句里折叠**：让从句拐回从前（「那只 `<物件>` 是 `<角色>` 搬进来那年买的」），主句仍向前推进，现在与过去共用同一副骨架。
3. **逗号推进，句号收束**：一个完整的意思走完才落句号；中间用逗号让气息不断，句号只留在真正的停顿与转折处。
4. **一个段落＝一个意识单元**：段落边界跟着注意力的移动走，不跟着字数走；注意力没转移就不分段。
5. **回忆与现实用同一语法层**：不写「那是很多年前」式的区隔标记，直接叙述，靠时态与人称暗示时间位置。
6. **从句套嵌不超过两层**：第三层要么前置成独立分句，要么砍掉；深度用并列的广度与句子的长度换，不往深处钻。
7. **心理先落到身体，再长回心理**：抽象情绪先给一个体感（喉咙发紧、指节抵住桌沿），再从体感长回思绪，形成可追踪的回路。
8. **长句后必有一个短句落地**：短句是读者的换气处，也是下一段缠绕的起跳点；这一条保住句长标准差。
9. **把标点当配气**：破折号用于插入与更正，省略号只用在真正说不下去的地方，感叹号尽量不用，逗号与句号承担全部推进。
10. **物象锚定时间，而非时间词锚定时间**：一段记忆可以由气味、光线、声音唤起；显性时间词只在跳跃的接缝处点一下。
11. **重复与变奏代替递进**：同一个词、同一个动作在句内回环一次，第二次出现时只换一个修饰，回响即成。
12. **叙述者偶尔出面收束**：一段意识流之后给一句判断或总结作落点，一句就够，不给第二句。

## 4. 最容易做砸的地方

- ❌ **长句没有内部节拍，一句到底**：读者读完不知停在哪，气息被拖垮。
  ✅ 每个长句至少两处呼吸，靠并列与插入制造停顿点；读一遍出声，换不上气就拆。
- ❌ **从句往深处套嵌，主语被埋**：追到第三层，已经不知谁在做那件事。
  ✅ 套嵌不过两层；主语一变就补出，宁可重复名词也不省略。
- ❌ **为长而长**：删掉全部定语与插入语，信息一点不少。
  ✅ 修饰必须携带新的感知、判断或回忆；不带信息的一律删。
- ❌ **把缠绕写成翻译腔**：套用长定语与关系词式的层层前置，中文的顺承被压平。
  ✅ 按中文语序让分句顺流而下，读起来长而不拗，不是长而拧。
- ❌ **标点滥用，把长句黏成一片**：靠破折号、省略号与连接词硬撑长度。
  ✅ 逗号与句号承担推进，其余标点各守额度（见第 2 节）。
- ❌ **时间折叠抛下读者**：一句话从此刻跳到多年前再跳回来，中间没有接缝。
  ✅ 折叠处给一个物象或一个显性时间词作锚，让读者踩得住。
- ❌ **心理只有内耗，没有外化出口**：人物悬在半空，读者跟不出一段意识的形状。
  ✅ 每段意识都落回身体与动作，再从那里长回去。
- ❌ **豁免当随便写**：长句脱离节拍、密度靠逗号与连接词注水，还援引风格档挡回去。
  ✅ 豁免的同时接受更严的自检（第 6 节）；豁免只限第 5 节列明项。

> 依据 `.cursor/tools/data/style-archetypes.json` 的 `archetypes["dense-interwoven"].exemptions`，按 `.cursor/templates/style-profile.md` §三的格式写进本项目 `主题/风格档.md`；未声明者不得豁免。

| 豁免的规则 | 放宽幅度 | 理由（本书为何需要） |
|---|---|---|
| `01-novel-language.mdc` §二.3「不超过 30 字的长句」 | 放宽到 **60 字** | 本原型签名手法：句内的感知叠加、心理回环与时间折叠需要更长的承载单位 |
| `01-novel-language.mdc` §二.3「严禁连续 3 个以上短句」 | **维持不变**，同样不得触碰 | 本原型不靠短句；短句仍只作换气与落地，无豁免必要 |

**不得豁免的红线**（任何风格都不能碰）：

- `00-novel-values.mdc` 全部条款（价值观宪法）——风格不构成任何理由。
- 正文不含元数据、批注、报告（`00-novel-meta.mdc` §二）；`05-novel-style.mdc` §二的分镜语言铁律照旧适用。
- 「读不懂」不能作为风格特征申报：主语可追踪、气息可读完是豁免的**前提**，不是可以牺牲的代价。
- 豁免只限上表第一行；`05-novel-style.mdc` 与 `01-novel-language.mdc` 的其余条款一律照旧。

## 6. 自检清单

- [ ] 每个长句都能一口气读完，且主语可追踪
- [ ] 从句套嵌不超过两层，主语转换处均已补出
- [ ] 删掉任一修饰成分，信息或感知会变化（没有空转的长句）
- [ ] 句长标准差落在区间内：长句群落之间有短句落地
- [ ] 至少三处时间折叠在句内完成，且读者跟得上跳跃
- [ ] 心理句都落回身体与动作，没有悬空的内耗
- [ ] 段落边界跟随注意力的移动，不是跟随字数切碎
- [ ] 感官优先通道为嗅觉/听觉，且存在同句双通道的交汇
- [ ] 破折号、省略号、感叹号、口语词各有额度，均未超额
- [ ] 显性时间词与解释性连接词都在额度内，没有通篇靠连接词拉着走
- [ ] 长句只用在信息密集或情绪需要缠绕处，没有全章滥用
