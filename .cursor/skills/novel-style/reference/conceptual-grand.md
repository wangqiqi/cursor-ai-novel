# 概念宏大（刘慈欣 / 阿西莫夫 / 勒古恩）· 风格原型

> **定位**：**设定驱动**型风格原型，服务于科幻、思想实验、文明尺度与制度推演类叙事；概念是主角，人物是概念的受力点。
> **用这个**：想写概念驱动、宏大尺度、观念辩论式对话、弱心理强逻辑的作品时；想让"一个想法"本身成为阅读快感的来源时。
> **不是那个**：不是设定说明文；不是术语越多越好；不是用"宏大"掩盖人物扁平。

## 1. 原型签名

**一句话**：用一个可被推演到极致的**概念**撬动尺度，让观念的碰撞代替情节的碰撞，让震撼从**尺度差**而非形容词中产生。

三条判据（三条都成立才算落在本原型）：

- **判据一 · 概念可推演**：全书推动力是一个能被读者复述、能自洽推演到底的设定命题，而非某个角色的欲望。
- **判据二 · 尺度在场**：时间跨度、空间尺或数量级至少有一项被明确写出来，并持续影响人物处境。
- **判据三 · 弱心理强逻辑**：人物内心戏被压低，情感靠选择与代价外化；关键段落是靠推理链而非抒情链推进。

## 3. 可操作技法

1. **概念必须落成可感知的尺度**：每个核心概念都要给出时间跨度、空间尺或数量级中的至少两项，用可比数字而非形容词。
2. **用一个具体人物的小处境承载大尺度（冷热对置）**：宏大远景与一件具体的、有体温的小事同节并置，让读者先相信小事，再接受大尺度。
3. **术语首次出现就地给出可操作定义**：一句话说清"能做什么 / 不能做什么 / 代价是什么"，不把定义推到后文解释段落。
4. **观念辩论要有真实利害**：辩论的胜负当场改变某个人的处境（资源、身份、生死、去留）；不辩论抽象的抽象。
5. **震撼来自"尺度差"而非形容词**：把两个读者已知的数量级并排摆出，让读者自己做减法；作者的惊叹词一律删掉。
6. **推理链必须可复述**：关键结论前给出完整的因为—所以链，允许解释连接词密度偏高；宁可多一步推论，不留一处跳步。
7. **以观念冲突替代烈度加码**：外部冲突可以持平，但价值观对撞必须往前推一步，且每次对撞要有一方付出可见代价。
8. **对话承担论证，动作承担情绪**：心理占比压低后，人物的动摇靠改口、手抖、算错、沉默来写。
9. **术语预算**：每节新增术语设上限（建议 1 主 2 辅），旧术语优先复用；已被解释过的概念不得重复解释。
10. **概念冲击后只留白一次**：给一个空镜或停顿即转入下一动作，不做第二次抒情，不追加总结。
11. **让反面立场也成立**：反方必须持有本作内部无法轻易驳倒的理由，否则辩论退化为宣讲。
12. **先给读者一次算错的机会**：在揭示真实尺度前，让读者用日常尺度估算一次并落空，落差才砸得实。

以上 12 条按"概念 → 尺度 → 代价 → 处境"的顺序落地；顺序颠倒会直接退化为 §4 的第一条。

## 4. 最容易做砸的地方

| ❌ 做砸了 | ✅ 处置方向 |
|---|---|
| **设定倾倒**：开会点名式讲解，人物排队复述设定 | 让概念在冲突中被迫出场——谁使用它，谁就受损或获利 |
| **人物沦为传声筒**：角色只为观念服务，没有私人利害 | 给每个辩论者一项与其公开立场相冲突的私人利害 |
| **术语自造却无法验证后果**：名词很响，正文里从无后果 | 每个术语配一次可观察的后果，且反向影响至少一个选择 |
| **尺度吹大但没有代价**（违反 `00-novel-values.mdc` 的无代价碾压禁令） | 大尺度必然压到具体的人身上：有人被牺牲、被放弃、被时代碾过 |
| **用"宏大"掩盖人物扁平** | 宏大由人物被逼出的选择生成，不能代替人物塑造 |
| **议论代替场景**：议论句占比失控，正文变成 essay | 每段议论由场景引出、以动作收束；超出区间即回退改写 |
| **概念堆叠导致读者掉队**：一节抛出多个新名词 | 每节一个主概念，其余只作背景音；未解释的概念不得参与关键转折 |
| **把结论当推理**：直接宣布"因此文明必然灭亡" | 补全中间步骤，并让一个反例先出现、再被消化 |

## 6. 自检清单

- [ ] ✅ **每个术语都能指出它在正文中造成的一次具体后果**（谁因此失去、得到或改变了什么）
- [ ] ✅ 核心概念首次出现时就地给定义，读者无需回翻
- [ ] ✅ 每个核心概念都落成可数或可比的尺度（时间跨度 / 空间尺 / 数量级至少两项）
- [ ] ✅ 每场观念辩论都改变了一个人的处境，而不只是改变了读者的认识
- [ ] ✅ 心理句占比落在本原型区间，人物的动摇主要由动作、失误或沉默外化
- [ ] ✅ 解释性连接词虽偏多，但全部用于机制推演，没有一句是用来给人物上课的
- [ ] ✅ 每个宏大场面之后都有一个具体的小处境承接（冷热对置已生效）
- [ ] ✅ 本节新术语数在预算内，旧术语被复用而非重新解释
- [ ] ✅ 议论段由场景引出、以动作收束，未取代场景
- [ ] ✅ 尺度带来的压迫有代价与反制可能，弱势一方未被无代价碾压
