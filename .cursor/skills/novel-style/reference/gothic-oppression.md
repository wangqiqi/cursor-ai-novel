# 哥特压迫（爱伦·坡 / 洛夫克拉夫特 / 雪莉·杰克逊）· 风格原型

> **定位**：风格原型参考，**非**强制；选定后由 `主题/风格档.md` 落成本书契约。
> **用这个**：想让恐惧从「认知一点点失效」长出来时；想让空间、声响与气味本身成为压迫来源，而不是靠怪物出场时。
> **不是那个**：不是形容词堆砌的许可证，也不是把叙述者写到失控、让读者失去锚点的借口。

## 1. 原型签名

一句话：**让日常秩序被反复轻微破坏，用听、闻、触碰的具体质地把不安一层层压上来，而恐惧之物始终不该有名字。**

| 判据 | 表现 | 反证 |
|------|------|------|
| **认知失效** | 人物的判断、记忆、仪器的读数依次变得不可信；恐惧来自「我原来搞错了」 | 恐惧来自一只被详细描写的怪物或一场追逃 |
| **氛围即主角** | 居所、光线、温差、气味承担主要张力；事件稀少但每一处陈设都在施压 | 靠情节密度撑场，环境只是背景板 |
| **不命名** | 恐惧之物始终只有轮廓、方位、声响，读者被迫自己补全 | 给恐惧之物起名、归类、说明来历与规则 |

## 2. 8 轴要点（怎么做到）

数值真源：`.cursor/tools/data/style-archetypes.json` 的 `archetypes["gothic-oppression"].targets`（表内为关键几项内联，完整轴以该文件为准）。

| 轴 | 本原型区间 | 怎么做到 |
|----|-----------|----------|
| 平均句长 | 20–36 字 | 句子允许长，但长在从句的**层层修饰**上（方位、质地、比较），不靠连词拖；句长用来拖延落点 |
| 句长标准差 | 11–20 | 波浪状句群：连续数句拉长蓄势，某一处骤降到十字以内，句法本身完成一次惊动 |
| 逗号密度 | 70–115 / 千字 | 逗号承担「一件东西被反复看清」的过程：补语、同位、追加的感官限定 |
| 破折号密度 | 3–9 / 千字 | 破折号用于**话被掐断**与突然插入的细节；比同类原型高，但每次都要有中断功能，不当装饰 |
| 平均段长 | 110–300 字 | 段落长、沉、不轻易换气；一段完成一次压迫升级。靠长段累积窒息感，不靠碎段跳跃 |
| 心理句占比 | 20–36% | 心理是主承重层：恐惧发生时先写判断怎么松动，再写身体怎么反应 |
| 内耗:外化 | 1.5–4.0 | 允许心理多，但心理必须落在**可核对的物证**上（那扇门本该是关的），不做纯思辨 |
| 第一人称占比 | 40–100% | 首选「我」在场见证；读者与叙述者共享同一套不完整的感官，天然限制视角 |
| 对话句占比 | 12–32% | 对白不多：用于说一句不合时宜的、或答非所问的话；对话是压迫的一环，不是信息交换 |
| 比喻密度 | 2.0–4.0 / 百字 | 比喻用来把不可名状翻译成**日常可触**的物：不是「无法形容的恐怖」，是「像被捂热的铜」 |
| 通感 | 8–18% | 有方向地转写：气味带出触感（潮冷）、声响带出体感（嗡鸣落在牙根）。禁止感官词平列 |
| 感官优先 | 听觉 / 嗅觉 / 触觉 | 先写听见什么、闻到什么、皮肤上是什么，视觉**最后**到位且不可靠；每节至少两个非视觉通道 |

- 解释连接词 3–8 / 千字：允许略高于极简原型，因为人物要把推断过程说出来；但推断必须挂在一个具体细节上。
- 感叹号 1–6 / 千字：恐惧不靠标点升级，只落在人物实在兜不住的那一两处。
- 省略号 2–8 / 千字 · 显性时间标记 3–9 / 千字：时间靠光线与体感推移带出，不靠「三天后」反复进场。
- 情绪-句式映射（与 `templates/style-profile.md` §六 对齐）：不安 → 句子变长、追加限定；惊动 → 骤然短句一句；恐惧深化 → 主语消失、只剩物；崩溃临界 → 句法仍完整但人称开始含混。

**补充轴（本原型易被忽略）**：轴 2 词汇指纹——口语标记 `colloquial_per_kchar` 1–6、术语 `jargon_per_kchar` 0–6、元叙事 `meta_per_kchar` 0–3，**现代口语与现代术语都要压到最低**（时间感靠器物与身体）；轴 7 叙述者态度——议论 `essay_ratio` 2–8，**只允许短促的判断句**，成段的解释会把不可名状讲成说明书。

## 3. 可操作技法

1. **让恐惧从认知失效里长出来**：依次让判断、日常读数和记忆互相矛盾；人物越努力确认，越确认不了。恐怖感来自「我一直在误读」。
2. **感官具体到质地**：不写「阴森潮湿」，写霉斑的绒毛碰到指背、水汽在领口变凉、铁器上一层红锈落在掌心。不洁、潮、腐都用可摸到的形态落地。
3. **用日常秩序的轻微破坏积累不安**：椅子被挪了半尺、门闩方向反了、昨夜的水还留在桌上。一次只错一点点，读者自己会警觉。
4. **不命名恐惧之物**：只用方位、轮廓、声响、留下痕迹的物指向它。**命名即降级**——一旦说清它是什么、什么规则，恐怖就变成设定。
5. **叙述者可靠性可疑，但锚点不能撤**：可以让「我」记错、前后不一致，但场景坐标（谁、在哪、什么时候、手上有什么）必须写实，读者才不会失去立足处。
6. **空间承担压迫**：写房间的比例、高度、回声、门与窗的位置；空间本身不配合人物，越走越不熟悉，同一处走廊第二次走过比第一次长。
7. **重复物象做变奏**：同一物（一扇窗、一种气味、一道水痕）在章节内反复出现，每次只改一个变量——温度、位置、在场的人。
8. **恐惧之物延迟出场**：给足等待与铺垫，用替代物先出现（声响、痕迹、被留下的东西），最后落到实处时反而比铺陈更轻。
9. **让话被说出口又立刻收回**：关键处用破折号掐断，或让说话的人自己改口；失语不用靠省略号装饰，靠句子变短变清楚。
10. **短段作呼吸阀**：长段落下沉到底之后，允许一个极短段落把呼吸放开一下，再压回去。全篇长段会让人麻掉。
11. **对白只留不合时宜的一句**：让某个人在错误的时候聊起天气、问起晚饭。正常话语比尖叫更让人不安。
12. **结尾留一个具体物证**：收束时回到一件可以被看见、摸到的东西上，把恐惧钉在读者能回指的位置。

## 4. 最容易做砸的地方

- ❌ **形容词堆叠取代具体感官**（本原型最容易被模仿坏的地方，也是最像洛氏的一处失手）：「阴森、可怖、难以形容、不祥」一路叠上去，读起来只有氛围词，没有一样东西。
  ✅ 每个形容词都必须能立刻指出它对应哪件物、哪个感官通道；指不出来的删掉，**一个都不留**。堆叠只允许叠在**具体感官**上。
- ❌ **为恐怖而恐怖，与人物利害无关**：怪事一件接一件，但人物没有想要的东西被威胁，读者不会替他害怕。
  ✅ 先立人物要保住什么（人、位置、身份、一件物），再让恐惧直接压在它上面；恐惧必须碍事。
- ❌ **叙述者失控导致弃读**：句子、人称、时空一起崩，读者连场景都拼不出来，只能放弃。
  ✅ 允许不可靠，不允许不可读：固定的场景坐标与可验证的物证要一直在场。
- ❌ **用暴力与血腥替代氛围（违反 `00-novel-values.mdc`「不美化暴力」，禁止）**：靠尸体、虐待、详细创伤描写顶住压力。
  ✅ 压迫靠不洁、声响、温度、气味与人物的判断失准完成；伤害若必须存在，只写**后果与痕迹**，不写过程，不写快感。
- ❌ **把恐怖一次性解释清楚**：用一段说明交代来历、规则、历史，气氛瞬间泄光。
  ✅ 只给可核对的现象与人物自己的解释——而且让人物的解释**部分错误**，错误本身继续施压。
- ❌ **通篇一个强度**：从第一段就绷到最紧，三页之后读者免疫。
  ✅ 按张弛安排：日常与松弛占前期多数，压迫逐级抬升，恐惧峰值只有一两处。
- ❌ **通感与比喻沦为装饰**：一串感官词平列，或比喻只是好看，不提供新信息。
  ✅ 转写必须有方向（从哪个通道到哪个通道），每个比喻都要交代身份、处境或前史里的一项。
- ❌ **只写内在，不动手**：心理占了大半篇幅，但人物不推门、不看窗、不摸那件东西。
  ✅ 心理一超一段，就用一个具体动作把它拉回物理世界；内耗与外化比值见第 2 节。

## 5. 合法偏离声明

本节的写法依 `templates/style-profile.md` §三：每条偏离须写「豁免哪条规则 / 放宽幅度 / 为什么只有这个原型需要」，并**逐条登记**到本书 `主题/风格档.md` §三；未登记不得豁免。以下三条取自 `.cursor/tools/data/style-archetypes.json` 的 `exemptions`（判定口径见本节末注）。

| 豁免的规则 | 放宽幅度 | 为什么只有这个原型需要 |
|---|---|---|
| `01-novel-language.mdc` §二.3「不超过 30 字长句」 | 放宽到 ≤48 字 | 本原型句长上界 36，超通用上限属签名（压迫感需要长句铺陈） |
| `01-novel-language.mdc` §一（八股检测维度表）「形容词堆砌 🔴」 | 允许**感官通道具体的**堆叠，修辞密度上限上移 | 本原型的签名手段就是「一件东西被反复看清」：霉、潮、锈、体温一层层叠上来。别的原型靠克制出味道，不需要这个口子 |
| （**判定口径，非豁免**）scanner 的堆砌判定口径 | 由「数形容词个数」改为「**指不出具体感官通道**才判 🔴」 | 只有把判定从数量移到具象，才能既放行风格，又拦住空洞形容词 |

**判定口径（写清才好执行）**：

- **只豁免「密度」，不豁免「空洞」**：能指出对应物与感官通道的形容词计入密度但不判堆砌；指不出来的，即使只有一个也照判 🔴。
- **能撑住密度的是轴 4（心理距离）与轴 8（感官与留白）**：心理句占比 20–36%、内耗:外化 1.5–4.0，密度才有人接住；密度超上限而心理与外化同时不达标，视为退化成形容词堆砌。
- **其余阈值维持不变**：`01` §二.3 的连续短句限制、全角标点、AI 套词黑名单、`05` §二「严禁分镜语言」一律不豁免。

**不得豁免的红线**（任何风格都不能碰，本原型同样没有例外）：

- `00-novel-values.mdc` 全部条款（价值观宪法）；尤其「**不美化暴力**」→ **维持强制**。本原型天然合规：压迫靠氛围而非血腥，不写伤害过程、不写施害快感。
- 正文不含元数据、批注、报告（`00-novel-meta.mdc` §二）。
- 不美化犯罪与强迫；亲密描写需自愿、清醒、可撤回。
- 不照搬具体作家的具体句子：只提炼特征，不复制文本。
- 不把真实人群、真实信仰、真实疾病写成恐惧之源——「不可名状」不得用来给现实群体贴标签。

## 6. 自检清单

- [ ] **恐惧的来源在本章内可被读者追溯到一处具体细节**（一件物、一次声响、一处位置的改变）
- [ ] 恐惧之物全程没有被命名、被归类、被说明规则
- [ ] 每个形容词都能指出它对应哪件物、哪个感官通道，没有孤立的氛围词
- [ ] 感官优先通道是听觉/嗅觉/触觉，每节至少两个非视觉通道，视觉最后到位
- [ ] 日常秩序的破坏是渐进的，每次只错一点点，没有一次性掀翻
- [ ] 叙述者可以不可靠，但场景坐标（谁/在哪/什么时候/手上有什么）始终写足
- [ ] 心理句占比与内耗:外化落在第 2 节区间，心理都落在可核对的物证上
- [ ] 比喻密度在 2.0–4.0 / 百字，通感有转写方向，不是感官词平列
- [ ] 全章张力有张弛，恐惧峰值只有一两处，前期留有日常与松弛
- [ ] 没有任何一处靠暴力、血腥、虐待过程顶住压迫感（`00-novel-values` 红线）
