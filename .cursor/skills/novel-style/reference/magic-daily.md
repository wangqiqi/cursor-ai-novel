# 魔幻日常（马尔克斯 / 鲁尔福 / 富恩特斯）· 风格原型

> **定位**：风格原型参考，**非**强制；选定后由 `主题/风格档.md` 落成本书契约。
> **用这个**：想写奇迹像天气一样被平静报出、时间打转、夸张以人物的相信为尺度时；想让一个家族或一片村镇替时间说话时。
> **不是那个**：不是「随便写都算魔幻」的许可证，也不是拿奇迹给情节兜底、把「不解释」当成「不交代」。

## 1. 原型签名

一句话：**把奇迹放到与下雨、做饭、报丧同一张桌上说出来，不解释、不惊叹，让它靠日常的密度自己站稳。**

| 判据 | 表现 | 反证 |
|------|------|------|
| **奇迹平铺** | 超常事件由叙述者用陈述句报出，语气与报一件家务事无异，前后不加惊叹与注解 | 奇迹一出场叙述者就抬高音量，或停下情节替读者讲原理 |
| **循环时间** | 同一件事以不同版本重现，细节缓慢偏移，时间呈环状而非直线 | 事件重复却毫无差异，读起来只是原地重播 |
| **信念尺度** | 夸张服从人物相信到什么地步，不服从客观可能 | 夸张只求耸动，与谁在信、信得多深无关 |

## 2. 8 轴要点（怎么做到）

数值真源：`.cursor/tools/data/style-archetypes.json` 的 `archetypes["magic-daily"].targets`（表内为关键几项内联，完整轴以该文件为准；轴的名称与单位见其 `_axes`）。

| 轴 | 本原型区间 | 怎么做到 |
|----|-----------|----------|
| 平均句长 | 25–42 字/句 | 句子偏长，一个句子常含两层推进：先落日常动作，再接一句偏移。不追求短促的撞击感 |
| 句长标准差 | 12–22 | 长短错落要明显。长句铺日常细节，短句报奇迹或落一个决断，落差本身就是口气 |
| 逗号密度 | 80–125 / 千字 | 逗号承担并置与推进，一句里可连缀数事；句号只落在事件真正换气处 |
| 破折号 | 2–7 / 千字 | 用于补充与自我修正，一次一句最多一个；不要用它替代逗号做主呼吸 |
| 平均段长 | 130–340 字 | 一段＝一个完整的生活切片（一顿饭、一夜、一次探访），不按字数切碎 |
| 比喻密度 | 1.8–3.5 / 百字 | 比喻中等偏上，但都取自身边物：布、炭火、牲畜、雨、伤口的味道。不用书面套词 |
| 通感句占比 | 6–15% | 让嗅觉带出温度、触感带出声响；通感成句出现，不整段都通感 |
| 心理句占比 | 8–20% | 心理不铺陈，多作信念与预感的短句出现；人物相信什么比他想什么更要紧 |
| 内耗:外化 | 0.6–1.8 | 内外大致相当。每写一段心事，就配一段手上的活计与屋里的动静 |
| 对话句占比 | 22–42% | 对白中等，多用于传递口信、旧怨与家族谱系；闲话里藏着时间 |
| 感叹号密度 | 1–5 / 千字 | 允许少量，但绝不落在奇迹上。奇迹用句号，人的争执才用感叹号 |
| 显性时间标记 | 6–16 / 千字 | 高密度，且常为**循环标记**：「又是」「照旧」「那年也一样」「每年到了这时候」。直线时间词与循环时间词要分开数 |
| 议论句占比 | 2–8% | 叙述者可以出面总结一句世理或家训，但一句即止，不给第二句 |
| 感官优先 | 嗅觉 / 触觉 / 热感 | 先写闻到什么、摸到什么、哪里发烫；视觉退后，避免以画面开道 |
| 解释连接词 | 3–8 / 千字 | 「因为/所以/原来」取中低位。奇迹的因果不靠连词缝，靠并置 |
| 口语标记密度 | 4–16 / 千字 | 方言与俗谚是叙事的底色，不是调味料；用它承担口传与家族记忆 |
| 专名术语密度 | 0–4 / 千字 | 几乎不造术语。设定不由名词表支撑，由反复出现的物与习俗支撑 |
| 元叙事标记 | 0–3 / 千字 | 不引档案、注释、书中书。荒诞感靠事件的排列，不靠文本装置 |

- 第一人称句占比 0–80%：家史口传与贴身第三人称都成立，不设限；但视角一旦定下，循环时间的每个版本必须在同一视角内报出。
- 情绪-句式映射（与 `.cursor/templates/style-profile.md` §六 对齐）：亢奋 → 句子更短、报出更多事实；悲伤 → 段落拉长，用仪式与物件铺开；恐惧 → 语序倒置（先报结果，再补日常），标点不变。

## 3. 可操作技法

1. **奇迹用平静口气陈述**：超常事件写成一句普通的陈述句，前后不加惊叹号、不加「竟然」「不可思议」、不解释原理；把它夹在做饭、喂牲口、报丧之间说完。
2. **日常动作不因奇迹中断**：奇迹发生后，人物的下一件事仍是洗碗、赶路、点灯。日常的继续才是奇迹可信的原因。
3. **循环时间：同一事件的不同版本**：让一件事重来二到三次，每次只改一个变量（谁在场、天气、谁先开口、死了谁），偏移即时间在走。
4. **夸张以人物信念为尺度**：夸张幅度由「谁相信、信到什么地步」决定，不由客观可能决定。不信的人看见平常，信的人看见奇迹，两套并存。
5. **家族/世代结构承载时间尺度**：用同名、重名的后代、重复的营生与同一间屋子，承载百年量级；时间不靠年代数字，靠人名与屋子的重复。
6. **现实细节密度是魔幻可信度的地基**：写足价钱、分量、气味、账目、季节与手艺。地基越实，奇迹越不需要解释。
7. **感官以嗅觉、触觉、热感开道**：进入一个场景先写闻到的味道、手上的质地、身上哪里发烫；视觉只作收尾。
8. **预兆与物象反复出现**：血、水、雨、炭火、某种草木气味在本章内重复两到三次，每次只改一处，重复即征兆。
9. **用精确的数字写荒诞**：给奇迹配上具体的数与量（多少天、多少步、多少斤），越精确越像真的，越不需要解释。
10. **让死者与缺席者保持在场**：亡者继续被谈论、被安排座位、被派活，处理成家常事，不当作惊悚点。
11. **叙述者不判定真假**：同一件事给出两套解释（习俗的解释与经验的解释），叙述者只报出两套，不裁定哪套对。
12. **段落走「日常—偏移—回到日常」三拍**：一段从一件琐事起手，中间落一处偏移，末尾回到琐事或一个动作，让读者始终有落脚处。

## 4. 最容易做砸的地方

- ❌ **魔幻变成万能解**：冲突一遇魔法就消失，情节再没有真正的难题。
  ✅ 奇迹只改变**处境**，不解决问题。它把人物推进更难的位置（欠债、失亲、被指认），代价必须落实。
- ❌ **不解释写成不交代**：作者自己也不知道规则，写起来随手开门关门。
  ✅ 读者不需要解释，**作者必须知道边界**：每一次奇迹都要能在 `主题/世界观.md` 里指回一条已登记的规则。
- ❌ **循环时间滥用，读者失去进度感**：同一件事反复出现却没人变化，全章像在原地绕圈。
  ✅ 每个版本必须留下**不可逆的痕迹**（死了一个人、少了一间屋、一个人再也不来），重复才有长度。
- ❌ **平静口气用错地方，把高潮也写平**：该收紧处照样不动声色，读者感觉不到章节的推力。
  ✅ 平静是**报奇迹**的口气；人的争执、诀别、暴力仍要收紧句子、放慢节拍，让强度有对比。
- ❌ **奇迹太密，日常被挤掉**：三页里全是超常事件，可信度的地基被抽走，读起来只剩奇观。
  ✅ 每处奇迹前后留足日常笔墨，按「一段日常配一处偏移」配比，宁少勿滥。
- ❌ **把荒诞当豁免，逻辑全崩**：时空、地理、人物年龄随意改，读者开始不信任叙述者。
  ✅ 荒诞只限于**奇迹本身**；物理层与社会层的其余部分照 `04-novel-worldbuilding.mdc` 保持闭合。
- ❌ **夸张没有尺度，越写越大**：为了惊人有求必应，最后什么都吓不到人。
  ✅ 夸张锚在一个人物的信念上，且全书尺度统一；先立住「谁信什么」，再定夸多大。
- ❌ **方言与俗谚堆成民俗展**：口语密度超区间，叙事变成风物志，人物反倒不在了。
  ✅ 口语只承担口传与家族记忆，一处方言配一处具体的人与事，超区间就删。

## 5. 合法偏离声明

本节的写法依 `.cursor/templates/style-profile.md` §三：每条偏离须写「豁免哪条规则 / 放宽幅度 / 为什么只有这个原型需要」，并**逐条登记**到本书 `主题/风格档.md` §三；未登记不得豁免。

依据：`.cursor/tools/data/style-archetypes.json` 的 `archetypes["magic-daily"].exemptions`。

| 豁免的规则 | 放宽幅度 | 为什么只有这个原型需要 |
|---|---|---|
| `.cursor/rules/04-novel-worldbuilding.mdc` §二「设定闭合性」的**完备性**（核心问题在设定内可解释） | 豁免「向读者解释」这一层：奇迹可在正文中始终不给原理与来源 | **奇迹本身不向读者解释属本原型签名**。一旦停下叙述去交代奇迹的原理，平静口气立刻断掉，奇迹降格为道具。但作者必须在 `主题/世界观.md` 登记它的**规则边界**——读者不需要解释，作者必须知道 |
| `.cursor/rules/01-novel-language.mdc` §二.3「不超过 30 字长句」 | 放宽到 ≤ 55 字 | 本原型平均句长落在 25–42 字，且常用逗号连缀数事以铺日常密度。上限不抬高，作者会被迫把生活切片切成电报句，密度与口气同时丢失 |

**维持强制，不予放宽**：`.cursor/rules/04-novel-worldbuilding.mdc` §四「新概念注册」照旧执行——引入任何新术语/概念/设定前，仍须在 `主题/世界观.md`、`主题/哲学母题.md` 或 `主题/<概念名>.md` 注册。奇迹可以不解释，但不能不登记。

**不得豁免的红线**（任何风格都不能碰，本原型同样没有例外）：

- `.cursor/rules/00-novel-values.mdc` 全部条款（价值观宪法）。
- 正文不含元数据/批注/报告（`.cursor/rules/00-novel-meta.mdc` §二）。
- `.cursor/rules/05-novel-style.mdc` §二「严禁分镜语言」：本原型常写空间与群体场面，最容易顺手写进电影术语，此为硬红线。
- 不美化暴力、犯罪、强迫；亲密描写需自愿清醒可撤回。

## 6. 自检清单

- [ ] 本章每个魔幻事件都有可追溯的规则边界（哪怕读者看不到）
- [ ] 本章所有奇迹均在 `主题/世界观.md` 有登记，无未注册的新概念
- [ ] 奇迹用陈述句报出，前后没有惊叹、解说或原理交代
- [ ] 奇迹改变了处境但没有代替人物解决问题，代价已落实
- [ ] 循环时间的每个版本都留下不可逆的痕迹，读者能感到时间在走
- [ ] 夸张的幅度与某个人物的相信程度对得上，两套解释并存且未被裁定
- [ ] 感官优先通道是嗅觉/触觉/热感，先写身体再写环境
- [ ] 段落多为完整生活切片，日常笔墨与奇迹偏移的配比未失衡
- [ ] 显性时间标记落在区间内，其中循环标记与直线时间词分别可控
- [ ] 口语与俗谚有具体的人与事承接，未超区间，未写成风物志
