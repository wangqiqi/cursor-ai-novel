# 冷峻极简（海明威 / 卡佛 / 余华）· 风格原型

> **定位**：风格原型参考，**非**强制；选定后由 `主题/风格档.md` 落成本书契约。
> **用这个**：想写短句并列、零度外化、冰山留白时；想让人物的疼由动作和物件自己说出来时。
> **不是那个**：不是「写得简单」的许可证，也不是省掉标点、把句子写干瘪、把该交代的都省略。

## 1. 原型签名

一句话：**把情绪从句子里撤走，只留下物、动作、与不肯说完的对白，让读者自己把温度补回去。**

| 判据 | 表现 | 反证 |
|------|------|------|
| **句法钝** | 短句并列推进，句号斩断，逗号惜用；名词与动词承担全部重量 | 靠形容词和排比制造气势 |
| **心理零度** | 叙述者不替人物命名情绪，只记录他做了什么、手里拿着什么 | 频繁出现「他很难过」「心里一阵酸楚」 |
| **冰山留白** | 因果、动机、结局的关键一段被有意留在水下，但水面上有可推回的痕迹 | 省略之后读者无从推回，只剩空白 |

## 2. 8 轴要点（怎么做到）

数值真源：`.cursor/tools/data/style-archetypes.json` 的 `archetypes["cold-minimal"].targets`（表内为关键几项内联，完整轴以该文件为准）。

| 轴 | 本原型区间 | 怎么做到 |
|----|-----------|----------|
| 平均句长 | 10–16 字 | 一个句号装一件事。写完先砍连接成分与状语，再读一遍是否还能再砍 |
| 句长标准差 | 6–12 | 不是全篇一样短。每段允许一两句 25 字上下的长句作锚，其余压短，靠落差出呼吸 |
| 逗号密度 | 30–55 / 千字 | 逗号只用于**同句内的先后动作**；并列关系改用句号切成两个句子 |
| 破折号 | 0–2 / 千字 | 近乎不用。补语、顿悟、插入语一律改写成独立短句或删掉 |
| 平均段长 | 40–110 字 | 段落短而完整：一段一个动作组或一次对话往返，不在一段里跨场景 |
| 比喻密度 | 0.3–1.0 / 百字 | 比喻稀缺，一次一击。要比喻就用日常可触的物，绝不用套词 |
| 心理句占比 | 2–8% | 心理只作极短的点状出现（半句），不铺陈，不连续两句都在心里 |
| 内耗:外化 | 0.15–0.35 | 每写一句心理，必须配三到六句外化动作；能外化的直接删掉心理那句 |
| 对话句占比 | 35–55% | 对白承担叙事主干。用对话交代关系与信息，胜过叙述者解说 |
| 感官优先 | 触觉 / 体感 | 优先重量、温度、湿度、疼痛、手里的质地；先写身体，再写环境 |
| 解释连接词密度 | 0–3 / 千字 | 「因为/所以/原来/其实/也就是」几乎不出现。因果靠事件顺序自己说明 |
| 省略号密度 | 1–5 / 千字 | 用，但克制：只落在说不下去的地方，不当作句末装饰 |

- 感叹号 0–2 / 千字：情绪强度靠动作的粗暴程度调节，不靠标点升级。
- 显性时间标记 3–8 / 千字：时间靠体感与光线推移带出，不靠「三天后」反复进场。
- 情绪-句式映射（与 `templates/style-profile.md` §六 对齐）：紧张 → 更短、更硬的动词；失落 → 句子变长一点点、省掉主语；愤怒 → 动作变具体变大，标点不变。

**补充轴（本原型易被忽略）**：轴 2 词汇指纹——口语标记 `colloquial_per_kchar` 2–8（对白里的生活语）、术语 `jargon_per_kchar` 0–3、元叙事 `meta_per_kchar` 0–1，**几乎为零是签名**（极简不靠术语与档案）；轴 7 叙述者态度——第一人称 `first_ratio` 0–60、议论 `essay_ratio` 0–3，**叙述者不点评**是底线（点评即破坏零度）。

## 3. 可操作技法

1. **用物和动作替代情绪词**：把「他很紧张」换成他反复拧一个已经拧紧的盖子；把「她不甘心」换成她把退回来的东西又摆回原位。
2. **对白省略追问与答句**：问一句，答非所问，或干脆不接。省略的部分靠下一段动作补足，读者自己补齐逻辑链。
3. **并列短句制造钝感**：连续三到五句同主语、同结构的短句累积，让麻木与重复变成体感；上限见第 5 节的豁免声明。
4. **留白：不解释因果**：只呈现场面与后果，中间那一步留给读者。但水面下必须藏得住——前后文要留下能推回去的物证。
5. **重复与变奏**：同一物象、同一句话在章节内重复出现，每次只改一个变量（位置、温度、谁在场），重复即强调。
6. **标点降噪**：能用句号的地方不用逗号，能删的破折号一律删，感叹号当禁忌处理。
7. **对话带活**：对白里只留动词和名词；删掉「他愤怒地说」这类副词的说话方式，让台词自己带情绪。
8. **少用形容词副词**：尤其是程度副词，全部替换为具象的身体感觉或具体量。
9. **关键时刻降速，不升高音量**：情感峰值处反而写得更短、更慢、更具体，只写手上的动作和视线落点。
10. **让物件承担记忆**：把前史压进一件反复出现的旧物，读者看到物件就想起事情，不必复述前情。
11. **幽默与抒情都降到最低**：冷峻底色里可以有一次极轻的幽默或一句抒情，之后立刻收回，不解释、不铺开。

## 4. 最容易做砸的地方

- ❌ **把极简写成贫乏**：通篇短句但没有任何实物与动作，读起来只是空洞。
  ✅ 每一句都至少推进一个具体信息：一个动作、一件物、一句有效对白。
- ❌ **连续短句失控变成电报体**：短句一路打下去，读者失去呼吸与落点。
  ✅ 允许的连续短句用尽后，用一个更长的句子或一段对话换气（上限见第 5 节）。
- ❌ **该给的信息也省掉导致读者断线**：人物关系、谁在说话、时空位置一律不交代，读者拼不出场景。
  ✅ 留白只留情绪与因果，**场景坐标必须给足**：谁、在哪、手上有什么。
- ❌ **用短句掩盖没有内容**：句子短是伪装，删掉修饰后剩下空壳。
  ✅ 先把内容写足，再逐句删到只留下必要成分，而不是一开始就写空。
- ❌ **省略标点当风格**：把引号、逗号删光来装冷淡，读者分不清谁在说话。
  ✅ 标点照常规写全，靠句子的长短和内容的选择变冷。
- ❌ **冷到没有温度，读者无法共情**：人物全程不露任何欲求与疼感。
  ✅ 冷的是**叙述语气**，不是人物的欲求：让人物仍然想要、仍然疼，只是不说。
- ❌ **把克制误当成不写**：该出场的冲突被略过，情节在原地打转。
  ✅ 克制是**呈现方式**，冲突该发生照样发生，只是不渲染、不解释。
- ❌ **通篇一个节奏**：从头到尾都是短句加句号，读者三页后麻掉。
  ✅ 按情绪曲线安排疏密：冷峻是底色，仍要有几处句法上的松弛与收紧。

## 5. 合法偏离声明

本节的写法依 `templates/style-profile.md` §三：每条偏离须写「豁免哪条规则 / 放宽幅度 / 为什么只有这个原型需要」，并**逐条登记**到本书 `主题/风格档.md` §三；未登记不得豁免。

| 豁免的规则 | 放宽幅度 | 为什么只有这个原型需要 |
|---|---|---|
| `01-novel-language.mdc` §二.3「严禁连续 3 个以上短句」 | 放宽到允许连续 6 个 | 并列短句的累积正是本原型的签名手法：用重复句式表现人物的钝与麻木。别的原型靠长短交替出节奏，不需要这个口子 |
| `01-novel-language.mdc` §二.3「不超过 30 字长句」 | **收紧**为 ≤ 25 字 | 本原型几乎不写长句；把上限压低，才能防止作者用长句逃回舒适区，把风格写成普通的叙述文 |

**不得豁免的红线**（任何风格都不能碰，本原型同样没有例外）：

- `00-novel-values.mdc` 全部条款（价值观宪法）。
- 正文不含元数据/批注/报告（`00-novel-meta.mdc` §二）。
- `05-novel-style.mdc` §二「严禁分镜语言」：本原型句法短促，最容易顺手写进电影术语，此为硬红线。
- 不美化暴力、犯罪、强迫；亲密描写需自愿清醒可撤回。

## 6. 自检清单

- [ ] 每处省略的信息，都能在前后文被推回（不是凭空留白）
- [ ] 相邻的连续短句没有空转，每句都带一个具体信息
- [ ] 对话中省略的追问与答句，没有造成读者认错说话人
- [ ] 情绪靠动作与物件外化，没有直接写情绪词的句子
- [ ] 逗号与破折号未超第 2 节区间，破折号接近零
- [ ] 比喻数量在区间内，且都落在日常可触的具体物上
- [ ] 感官优先通道是触觉/体感，先写身体再写环境
- [ ] 「因为/所以/原来」这类解释性连接词没有超额，因果靠事件顺序说明
- [ ] 每个场景的坐标（谁/在哪/手上有什么）都给足了
- [ ] 全章节奏有疏密起伏，不是从头到尾同一个句法
