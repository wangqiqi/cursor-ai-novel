# 世界观打包 · novel-world

## 触发场景

- 新建一个世界观（科幻/奇幻/架空）
- 已有 `主题/世界观.md` 但需要补充/修正
- 需要创建地点卡、组织卡、概念卡
- 检查现有设定的闭合性

## 输入

- 1-2 句话的世界观雏形 / 类型（科幻/奇幻/现实/混合）
- 复用：现有 `主题/世界观.md`、`主题/哲学母题.md`（仅 Q6=深度；**文件名固定**，不支持改名）

## 三层结构（强制）

| 层级 | 内容 | 文件归属 |
|------|------|---------|
| **物理层** | 时代、技术、地理、气候 | `主题/世界观.md` |
| **社会层** | 制度、组织、经济、权力结构 | `主题/世界观.md` 或 `主题/<组织>.md` |
| **哲学层** | 元规则、终极真相、最高存在 | `主题/哲学母题.md`（或项目自选母题文档） |

> 三层不能混淆：
> - ❌ 把哲学层当成物理层
> - ❌ 让物理层解释哲学层

## 5 维框架

每个新设定明确：

1. **时间**：故事发生在何时？
2. **空间**：物理/虚拟/多重？
3. **规则**：物理规则/魔法规则/社会规则？
4. **力量**：谁掌握力量？怎么流动？
5. **代价**：使用力量要付出什么？

## 工作流

### 1. 类型判定

- 科幻（硬/软）/ 奇幻（高/低/暗）/ 架空 / 现实
- 决定技术/魔法的"硬度"

### 2. 时代背景

- 距今多久？
- 关键历史事件（1-3 个）
- 当前的"失衡点"（什么出了问题？）

### 3. 核心矛盾

- 一句话：什么看似美好？实际多残酷？
- 例（占位）：<表层乌托邦> 看似 <表面美好>，实则 <隐藏代价>

### 4. 资源稀缺

必须明示（高压社会类必备）：

- 能源 / 算力 / 空间 / 时间 / 注意力

### 5. 系统设定

- 系统由谁控制？
- 系统的"善意"如何显化？
- 反抗的局限是什么？

### 6. 感官基调（小说专属，按身体感优先级）

> **重要**：小说创作，**不是美术设定**。基调通过**文字描写**传递，不是"画面调色板"。

每个场景/世界必须有，按**身体感优先级**排列：

| 通道 | 内容 | 优先级 |
|------|------|--------|
| **触感 / 体感** | 冷 / 热 / 痛 / 麻 / 湿度 / 气流 | ⭐⭐⭐ 最高 |
| **嗅觉** | ≥ 3 种标志性气味 | ⭐⭐⭐ 高 |
| **听觉** | 环境音 + 标志声响 + 静默 | ⭐⭐ 高 |
| **味觉** | 入口的味道（食物 / 血 / 空气） | ⭐⭐ 中 |
| **色调 / 视觉** | 仅辅助，避免堆砌 | ⭐ 辅助 |

### 7. 哲学层 / 最高存在

- 是否存在"元规则"？
- 与 `主题/哲学母题.md` 的母题对齐

## 输出

### 主输出

`主题/世界观.md`（如已有则识别并**扩展**，不覆盖）

### 子输出

- `主题/哲学母题.md`（仅 Q6=深度；**文件名固定**，不支持改名）
- `主题/<概念>.md`（每个独立概念一条）
- `主题/<地点>.md`（地点卡，模板见 `.cursor/templates/location-card.md`）
- `主题/<组织>.md`（组织卡，模板见 `.cursor/templates/faction-card.md`）

> **归属边界**：组织/派系/地点作为**设定条目**由本技能维护；其中的人物代理与群体弧光归 `novel-character`。
> 所有新概念按 `04-novel-worldbuilding.mdc` §四 注册（定义 / 命名寓意 / 来源原理 / 作用代价 / 感官特征 / 与已有概念的关系 / 首次出现章节）。

## 闭合性自查

- [ ] 时间线无矛盾
- [ ] 地理无矛盾
- [ ] 技术规则闭合
- [ ] "神"不能打破自己定的规则

## 调度

- 设定登记完成后，调度 **`novel-world-keeper`** 做闭合性自查：三层结构、新概念注册完整性、感官基调、时间线/地理/技术规则闭合。
- 概念是否"用得上"由 `novel-plot` 的冲突轴判断，本技能不保留用不上的设定。

## 反模式（避免）

- ❌ 哲学层被解释为物理层
- ❌ 资源稀缺不明确
- ❌ 系统的"善意"缺失
- ❌ 反抗无限制（无代价、无约束的碾压式「爽」；允许有代价的情绪兑现，见 `02-novel-plot-design.mdc` · `skills/novel-plot/reference/reader-rewards.md`）
- ❌ 设定内有未使用的概念
