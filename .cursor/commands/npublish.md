# /npublish · 外发打包

## 用法

```bash
/npublish [版本]
```

## 启动前硬闸

| 闸 | 要求 | 不满足时 |
|---|---|---|
| **情节尺** | 主线节拍闭合、终局落地 | 只出阶段包，不升主版本 |
| **出版尺** | 节长/高潮有肉、外发硬伤清零 | **禁止**打 v1.0 |
| **体量尺** | 达到作者自定的长制/短制目标 | 只作进度，**不**挡外发 |

三把尺**分开记**，禁止合成一个「过了」（`skills/novel-plan/reference/universal-gates.md` §7）。

## 流程

加载 skill **novel-publish**：

1. **三尺打分** —— 逐尺记录绿/未绿与依据。
2. **外发硬伤清零** —— 正文禁作者元叙事（「第 N 章」）、未落地专名剧透、控制层术语当对白（§8）。
3. **技术打包** —— 合并 `章节/`（**唯一源**）为 `build/<书名>_全文.md`；目录 + 字数 + 敏感词扫描。
4. **推介材料** —— 写 `主题/推介包.md`（一句话推介 / 三百字简介 / 腰封 / 模拟短评 / 上架填写卡）。
5. **归档** —— `CHANGELOG.md` 记版本；`git tag` 仅当用户同意；备份进 `.cursorGrowth/archive/`。

## 输出

| 文件 | 是否版本化 |
|------|-----------|
| `主题/推介包.md` | ✅ 真源 |
| `build/<书名>_全文.md` | ❌ 产物（`build/` 被 gitignore，可重跑） |
| `build/<书名>_统计报告.md` | ❌ 产物 |

## 🔴 铁律

- 出版尺未绿 **禁止**升主版本（如 v1.0）。
- 简介 / 目录**不得剧透核心反转**。
- 只按 `章节/` 写推介，**不把 `主题/` 当读者读物**。
