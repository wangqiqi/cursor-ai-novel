# /nfix · 修订流水线

## 用法
```bash
/nfix <章节号> [轮次]
```

## 5 轮修订概览
1. **故事层**：逻辑、节奏、动机、冲突是否升级。
2. **场景层**：钩子类型、爽点兑现、衔接；对照节奏窗（开篇/高潮密度）；可选核对本强调性（`emotion-craft`）。
3. **文字层**：去 AI 味、密度控制、节奏；动态画面（见 `05-novel-style`）。
4. **主题层**：母题落地、意象呼应。
5. **校对层**：错别字、标点、格式；建议朗读捕捉语病。

## 建议顺序（与通义「三轮」对齐的压缩读法）
结构（1–2）→ 细节/对话（3）→ 抛光（5）；中间可**搁置数日**再以读者视角回看。  
初稿未完时不要在第 3–5 轮上过度纠结（先完整再完美）。
