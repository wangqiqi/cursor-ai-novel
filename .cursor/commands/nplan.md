加载 skill **novel-plan**：

1. **阶段 1** — 需求澄清：用 AskQuestion 收集歧义（≤ 6 个，一次并行提交；无该工具则正文编号选项）
2. **阶段 2** — 现状盘点：扫描 `主题/`（含 `主题/人物/`）`章节/` `.cursorGrowth/plan.md` `CHANGELOG.md`
3. **阶段 3** — 任务分解：拆 ≤ 5 步可审核子任务（MECE + 完成定义）
4. **阶段 4** — 风险评估：识别三类（资产/一致性/范围）
5. **阶段 5** — 写入 `.cursorGrowth/plan.md`：**按 `.cursor/templates/plan.md` 的 schema 更新**（头部 9 字段 + `Active sprint` + `下一 Sprint 候选`）；阈值取 `主题/通用约束.md`（无则按默认，节字数 ≤ 5000）

| 用这个                                 | 不是这个                                 |
| -------------------------------------- | ---------------------------------------- |
| 任务 ≥ 5 步 / 跨文件 / 改设定 / 新项目 | 简单询问 / 单文件改动 / 一次性能完成     |
| 想"先想清楚再动手"                     | 已经有具体 `.cursorGrowth/plan.md` 要执行 → **`/nrun`** |

规划完成后**必须等待用户确认**（"开始"/"go"/"确认"），不得直接动手。
