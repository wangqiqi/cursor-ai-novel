# 敏感词表 · 格式示例（占位，请按目标平台替换）
#
# 用法：
#   1) 复制本文件为项目文件 `主题/敏感词表.md`，把下面的占位词换成你目标平台的真实词表。
#   2) 本工具（.cursor/tools/check_manuscript.py）会优先读 `主题/敏感词表.md`；
#      项目无该文件时才回退读本示例文件。
#
# 格式：
#   - 每行一个词或短语；`#` 开头为注释；空行忽略；Markdown 表格行与 `>` 引用行忽略。
#   - 一行一个即可，不要用逗号分隔。
#   - 词表属于**项目特化**，不要回写 `.cursor/`（见 rules/00-novel-meta.mdc）。
#
