## 二、视角切换规则（强制）

| 规则 | 口径 |
|------|------|
| **一节一视角** | 同一节内不得切换 POV 视角（否则读者失去定位） |
| **切换标记** | 切视角处单独一行 `> 【视角：<人物> · <地点> · <时间>】`（`rules/05-novel-style.mdc`） |
| **禁止 `##` 切块** | 不得用 `##` 标题做视角/场景切块（`05` §四） |
| **切换有理由** | 每次切换须能回答"为什么此刻必须换这个人的眼睛看" |
| **频次控制** | 同一章内 POV 数不超过 <n> 个（建议 ≤ 3）；线越多，单线单次出场越长 |
| **多线交叉章** | 交叉点章可临时提高频次，但须在章前卡声明 |

## 三、信息边界台账（防越界知情）★核心

> 多线最常崩的地方：某条线的角色**知道了只有另一条线才可能知道的信息**。
> 每完成一批章节，回填一次本表。

| 信息 / 真相 | A 线是否知道 | B 线是否知道 | C 线是否知道 | 读者是否知道 | 首次揭示位置 |
|------------|-------------|-------------|-------------|-------------|-------------|
| <关键真相 1> | ❌ | ❌ | ❌ | ❌ |  |
| <关键真相 2> |  |  |  |  |  |

**口径**：
- 角色获得信息**必须有来源**（在场 / 被告知 / 读档 / 推断），来源要写进正文。
- 读者知道 > 角色知道 → 制造信息差张力（合法且推荐）。
- 角色知道 > 读者知道 → 必须靠"行为暗示"而非旁白解释，否则是**作者替角色偷看剧本**。

## 七、反模式

- ❌ **越界知情**：B 线角色用上只有 A 线才知道的信息
- ❌ **一条节内换三次视角**：读者失去定位，代入感崩塌
- ❌ **线开了不收**：新线没有并轨计划，越长越散
- ❌ **节奏掉队**：某线长期不动，读者忘掉后突然回归
- ❌ **伪多线**：所有线说同一件事、共享同一 Want
- ❌ 用 `##` 或分镜式标题充当视角切换
