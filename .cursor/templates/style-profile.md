## 三、合法偏离声明（★ 本层存在的主要理由）

> **为什么需要这张表**：`01-novel-language.mdc` 与 `05-novel-style.mdc` 的阈值是为"通用好文风"设的。
> 某些风格**天然违反**它们（海明威就是连续短句；福克纳就是 60 字长句；莫言就是高密度比喻）。
> 没有这张表，Agent 会在"模仿风格"和"遵守规则"之间反复打架，最后交出四不像。
>
> **规则**：每条偏离必须写「豁免哪条规则 / 放宽到什么幅度 / 为什么这对本书成立 / 涉及哪个指标」。
> `check_manuscript.py --style` 会把落在豁免范围内且**已在此声明**的项判 **🟡（已声明豁免）**；**未声明就不得豁免**。

| 豁免的规则 | 放宽幅度 | 理由（本书为何需要） | 涉及指标（填 §二 的指标名，逗号分隔） |
|---|---|---|---|
| 例：`01` §二.3「严禁连续 3 个以上短句」 | 放宽到允许连续 6 个 | 主原型签名手法，用于表现人物麻木 | `<填指标名，如 avg_sentence_len>` |
|  |  |  |  |

**不得豁免的红线**（任何风格都不能碰）：
- `00-novel-values.mdc` 全部条款（价值观宪法）
- 正文不含元数据/批注/报告（`00-novel-meta.mdc` §二）
- 不美化暴力、犯罪、强迫；亲密描写需自愿清醒可撤回

## 七、自检清单（每章完成后勾）

- [ ] 本章句长分布落在 §二 目标区间（或偏差已在报告说明）
- [ ] 修辞密度未超目标上限；比喻都具象可感（非空洞形容词）
- [ ] 心理/外化比符合目标（不擅自加内心戏，或反之）
- [ ] 感官优先通道与目标一致
- [ ] 未使用 §四 禁用万能词
- [ ] §三 声明的豁免项**只在本风格需要处使用**，未滥用为"随便写"的借口
- [ ] 情绪-句式映射（§六）在本章至少两处生效

## 八、反模式

- ❌ 把"风格"当免罪金牌：豁免只限 §三 列明项，其余规则照旧
- ❌ 只抄词汇不学句法（最容易做出"风格皮肤"）
- ❌ 为凑指标而机械堆短线/堆长句（风格是结果，不是 KPI）
- ❌ 中途悄悄改风格目标而不更新本档（改档须走 `/nplan`）
- ❌ 照搬某作家的具体句子或段落（只提炼特征，不复制文本）
