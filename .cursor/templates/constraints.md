## 一、篇幅与结构

### 1.1 颗粒度档（先定「章」是什么，再谈其他）

> **这是全项目最重要的一个约定**：`章` 的含义由本档决定，`节拍表 / 节奏窗 / 章前卡 / chapter-brief` 全部按它解释。
> 选错档的典型症状：网文按母版默认（大章）写 → 每章 3 万字、读者一天看不完；出版按网文档写 → 章节碎成上千条。

| 档 | 适用 | 单章字数 | 单章节数 | 「一章」实际是 | 节奏窗 N |
|----|------|---------|---------|--------------|---------|
| **A · 网文连载** | 平台日更 / 追读制 | 2000–4000 汉字 | 1–2 节 | 读者的「一话」 | 总章数（可数百–上千） |
| **B · 出版长篇** | 实体出版 / 单本长篇 | 6000–12000 汉字 | 3–6 节 | 书里的「一章」 | 实际章数 |
| **C · 大章 / 卷**（母版默认） | 大章制 / 单章多场景 | 30000–60000 汉字 | 5–15 节 | 近似「一卷」 | 大章数（节奏窗按大章） |

| 项 | 值 | 说明 |
|----|-----|------|
| **颗粒度档** | A / B / C | 选一档；混合制请写明例外 |
| **篇幅档** | 短篇 / 中篇 / 长篇 / 史诗 | 来自 Q2 |
| **计划总章数 N** |  | **按上表所选档的「章」计数**；用于换算节奏窗（`skills/novel-plot/reference/opening-protocol.md`） |
| **单章节数窗** | 按所选档（见 1.1） | 超出需在章前卡说明 |
| **单章字数窗** | 按所选档（见 1.1） | — |
| **单节目标字数** | 默认 2000–5000 汉字 | 见下节硬上限 |
| **单节硬上限** | 默认 5000 汉字 | 超过须用户特批并记录理由 |
| **叙事结构** | 三幕 / 起承转合 / 英雄之旅 / 自由 / 多线 | 来自 Q5 |

> **一致性红线**：`主题/总览.md` 的「计划总章数 N」、`主题/节奏窗.md` 的「计划总章数 N」、本表的 N 必须**同一含义同一数值**。
> 改档等于改全书标尺 —— 必须重算节奏窗，并走 `/nplan`（属"核心设定变更"）。
