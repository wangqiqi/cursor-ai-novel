# 基座模板 · `.cursor/templates/scaffold/`

> **新小说项目的骨架模板库**。
> 被 `/nnew` 命令引用，用于一键创建新项目。

---

## 一、目录结构

```
.cursor/templates/scaffold/
├── README.md                       # 本文件
├── 主题/                           # 主题层基座
│   ├── 人物/
│   │   └── .gitkeep
│   ├── 世界观.md                   # 空模板
│   ├── 主线剧情.md                 # 空模板
│   ├── 哲学母题.md                 # 空模板（按需）
│   └── 总览.md                     # 模板（含目录说明占位）
└── 章节/
    └── .gitkeep
```

## 二、设计原则

1. **完全通用** —— 所有内容用 `<...>` 占位符，不绑定任何具体项目
2. **扁平化** —— 全部在 `主题/` 下，避免多层目录嵌套
3. **基座而非内容** —— 这是骨架，不是文案。用户调用 `/nnew` 后，需自行填充

## 三、使用方式

### 方式 1：通过 `/nnew` 命令（推荐）

```bash
/nnew <项目名>
```

命令会用 `AskQuestion` 问 3 个关键选择题，然后：
1. 复制 `scaffold/主题/` 到 `<新项目>/主题/`
2. 复制 `scaffold/章节/` 到 `<新项目>/章节/`
3. 用项目名替换 `<项目名>` 占位符
4. 生成 `CHANGELOG.md`、`plan.md`、`.cursor/` 引用

### 方式 2：手动复制

```bash
# 复制整个基座到新项目根目录
cp -r .cursor/templates/scaffold/主题/ <新项目>/主题/
cp -r .cursor/templates/scaffold/章节/ <新项目>/章节/
```

## 四、按需启用模板

`/nnew` 命令会根据用户选择决定**复制哪些模板**：

| 用户选择 | 启用的模板 |
|---------|----------|
| 轻量哲学 | `哲学母题.md` 标记为"未启用"，可手动删除 |
| 深度哲学 | 完整复制 `哲学母题.md` |
| 不启用哲学母题 | 完全不复制 |

## 五、维护规则

- **修改模板前**：评估影响范围（是否破坏通用性）
- **新增强制文件**：在 `00-novel-meta.mdc` 中同步登记
- **删除文件**：需谨慎，先评估是否所有项目都需要
